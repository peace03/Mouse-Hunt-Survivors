# 코드 합성 효과음 37종

`Workflow/Design/아트/아트_디렉션.md`의 효과음 목록 순서와 이름을 따른다. 외부 음원 없이 진동파·대역 제한 잡음·공명·음정 변화로 합성했다.

- 형식: 48 kHz, 16-bit PCM WAV, 모노. 위치 음향과 UI 양쪽에서 사용할 수 있다.
- 음원별 최대 음량: -6~-15 dBFS. 발소리·지속음은 작게 설정했다. 실제 게임의 믹싱은 별도 조정이 필요하다.
- 반복 재생: 코골이, 웅~, 윙~, 공 굴림. `AudioSource.loop`를 켜고 시작·종료에 짧은 볼륨 페이드를 적용한다. WAV 자체에는 Unity의 loop 설정이 저장되지 않는다.
- 발소리는 한 걸음이다. 이동 방식에 따라 같은 파일의 음량과 재생 간격을 바꾼다.
- 게으름냥 기상은 여러 마리가 동시에 깨도 한 번 재생한다. 6:00 승리에는 알람만 쓴다.
- 게임의 기존 `GameAudio` 연결은 변경하지 않았다. 이번 산출물은 교체 가능한 오디오 에셋이다.

## 재생성·검사

저장소 루트에서 설치된 Python과 NumPy로 실행한다. 같은 시드로 재현하며 기존 WAV가 다르면 덮어쓰지 않고 중단한다.

```powershell
python -B Workflow/Tools/generate_sfx.py
python -B Workflow/Tools/generate_sfx.py --check
```
