# 고양이 종류

<aside>
📌

**상태:** 초안

**관련 결정:** D-011, D-017, D-038, D-042, D-047

**한 줄 요약:** 호기심냥(미끼)·게으름냥(잠)·사냥꾼냥(공)의 반응표, 우선순위, 고유 행동과 수치.

</aside>

## 1. 목표

- 고양이 3종은 체력이나 속도보다 무엇에 속는지로 구분한다. 종류마다 열쇠가 하나다.
  - 호기심냥: 미끼에 속는다.
  - 게으름냥: 잠을 쓴다. 깨우면 벌, 재우면 기회다.
  - 사냥꾼냥: 공에 속는다. 덮치기를 읽고 피하면 떨어진다.
- 추적을 끊는 것도 그 열쇠다. 같은 판 안에서 상대에 따라 쓸 도구가 바뀐다.
- 공통 규칙은 [고양이 공통](고양이_공통.md)을 따른다. 아래는 종류별 차이만 적는다.

## 2. 규칙

**반응표**

| 자극·상황 | 호기심냥 | 게으름냥 | 사냥꾼냥 |
|---|---|---|---|
| 일반 소리 | 조사 | 자는 중: 무시. 깨어 있음: 조사 | 조사 |
| 큰 소리 | 조사 | 자는 중: 깨서 그 지점으로 기상 질주. 깨어 있음: 조사 | 조사 |
| 잔상 | 추적을 끊고 잔상 지점 조사 | 자는 중: 깨서 잔상 지점으로 기상 질주. 질주·추적 중: 끊고 잔상 지점 조사 | 무시 |
| 미끼 | 추적 중에도 감(내성 중에는 무시) | 아래 '미끼로 재우기' | 무시 |
| 공 굴림 소리 | 무시 | 무시 | 공에게 감 |
| 공이 스스로 멈출 때(큰 소리) | 조사 | 자는 중: 깸. 깨어 있음: 조사 | 공에게 감 |
| 근접 2m | 추적 | 자는 중: 무시. 깨어 있음: 추적 | 추적 |
| 함정 피격 | 기절 뒤 스위치 조사 | 자는 중: 피해 ×2, 기절 없이 스위치로 기상 질주. 깨어 있음: 기절 뒤 스위치 조사 | 기절 뒤 스위치 조사 |
| 추적을 끊는 열쇠 | 미끼, 잔상 | 잔상(긴 직선에서 멀리 벌린 뒤 조용히 해도 놓침) | 공, 헛디딤 |

**우선순위**
- 호기심냥: 미끼 > 잔상 > 추적 > 큰 소리 = 일반 소리
- 게으름냥(깨어 있음): 잔상 > 기상 질주 = 추적 > 미끼 > 큰 소리 > 일반 소리
- 사냥꾼냥: 공 > 추적 > 큰 소리 = 일반 소리. 공이 스스로 멈출 때 나는 큰 소리도 사냥꾼냥에게는 '공' 순위다.
- 미끼로 추적을 끊을 수 있는 것은 호기심냥뿐이다.

**호기심냥**
- 청각 배율이 높아 같은 소리에 먼저 반응한다.
- 미끼를 먹기 시작하면 미끼 내성이 걸린다 (→ [치즈 던지기](../플레이어/치즈_던지기.md)).

**게으름냥: 잠**
- 판 시작: 자기 수면 지점에서 잠든 채 시작한다. 수면 지점 2곳은 게으름냥 순서대로 1곳씩 배정한다 (위치는 → [맵](../월드/거실_주방_맵.md)).
- 자는 동안: 순찰하지 않는다. 일반 소리, 미끼, 공 굴림 소리, 근접을 무시한다.
- 기상: 큰 소리(공 멈춤 포함), 잔상, 잠든 채 함정 피격에만 깬다.
  - 깨면 그 소리 지점으로 기상 질주한다. 피격으로 깼으면 그 함정의 스위치로 질주한다.
  - 같은 순간 여러 마리가 깨도 기상음은 한 번만 울린다.
- 기상 질주
  - 목표는 고정된다. 질주 중 들린 큰 소리·일반 소리·미끼는 무시한다. 달리는 쥐가 질주하는 게으름냥을 끌고 다닐 수 없다.
  - 잔상만 질주를 끊는다.
  - 질주 중 쥐가 근접 2m 안에 들어오면 같은 순위의 더 새로운 자극이라 추적으로 바뀐다.
  - 목표 지점에 도착하거나 질주 최대 시간이 지나면 끝나고 그 자리를 조사한다. 조사 중에는 다른 고양이처럼 새 소리를 따라 조사 속도로 움직인다.
- 잠든 채 피격: 피해가 2배이고 기절하지 않는다.
- 미끼로 재우기: 깨어 있고(조사·순찰·귀가 중) 질주·추적 중이 아니며 5단계 전이면 미끼를 먹는다. 먹기가 끝나는 순간 그 자리에서 잠든다.
- 귀가: 5단계 전에는 목표가 끝나 순찰로 돌아갈 때 순찰 대신 자기 수면 지점으로 순찰 속도로 걸어가 잠든다. 귀가 중에도 깨어 있으므로 소리를 조사하고 미끼를 먹는다.
- 재입장: 5단계 전에는 펫도어에서 자기 수면 지점으로 걸어가 잠든다. 걷는 동안은 깨어 있다. 증원으로 들어올 때도 같다.
- 잠드는 순간 검사: 잠드는 모든 순간(먹기 끝, 귀가·재입장으로 수면 지점 도착)에 5단계 이상이면 잠들지 않고 순찰한다. 5단계에는 잠든 게으름냥이 없다.
- 5단계 강제 기상: 5단계가 되면 잠든 게으름냥은 질주 없이 그 자리에서 깨어 순찰한다 (단계 전환은 → [시간 진행](../진행/시간_진행.md)).
  - 그 뒤로는 미끼를 무시하고 귀가하지 않는다.
  - 5단계 이후 입장·재입장은 깬 채로 순찰한다.

**사냥꾼냥: 덮치기와 공**
- 미끼와 잔상을 무시한다.
- 예측 덮치기
  - 예측 착지점은 착지하는 순간 쥐가 있을 위치다. 발동을 판단할 때는 지금 위치 + 쥐 속도 × (준비 시간 + 도약 시간)으로 본다.
  - 추적 중이고, 쿨타임이 찼고, 예측 착지점이 발동 거리 안이면 발동한다. 쥐 자체의 거리는 보지 않는다.
  - 준비: 제자리에 웅크린다. 착지 표시가 예측 착지점을 따라가다 마지막 0.2초에 고정된다. 고정할 때의 예측점은 그 순간 위치 + 쥐 속도 × 0.5초다.
  - 도약: 고정된 점으로 뛴다. 점이 도약 거리보다 멀면 도약 거리 끝에 떨어진다.
  - 착지 판정 반경 안에 쥐가 있으면 잡는다.
- 헛디딤: 빗나가면 헛디딘다. 헛디딤이 끝나면 추적이 끝나고 착지 지점을 조사한다.
- 공
  - 공 굴림 소리나 공이 스스로 멈출 때의 소리를 들으면 추적 속도로 공의 지금 위치로 간다. 멈춘 공에도 간다.
  - 공의 예측점(남은 굴림 거리까지만)이 발동 거리 안이면 같은 방식으로 덮친다. 착지 때 공이 착지 판정 반경 안에 있으면 잡고 공놀이를 한다.
  - 공놀이가 끝나면 순찰로 돌아간다. 덮쳐 세운 공은 멈춤 소리를 내지 않는다. 공놀이 중 공의 상태는 [장난감 공](../월드/장난감_공.md)에 있다.

**보름달**
- 7일째 규칙 보름달(→ [캠페인](../진행/캠페인.md))은 추적 속도에만 곱한다. 사냥꾼냥이 공으로 가는 속도도 추적 속도다.
- 게으름냥 기상 질주와 사냥꾼냥 도약에는 곱하지 않는다.

## 3. 수치

| 고양이 | 체력 | 추적 속도 (m/s) | 청각 배율 |
|---|---|---|---|
| 호기심냥 | 3 | 4.5 | ×1.3 |
| 게으름냥 | 5 | 4.0 | ×1.0 |
| 사냥꾼냥 | 4 | 5.0 (보름달 5.5) | ×1.5 |

| 항목 | 값 | 비고 |
|---|---|---|
| 게으름냥 수면 지점 | 2곳 | 위치는 [맵](../월드/거실_주방_맵.md) |
| 게으름냥 기상 질주 속도 | 5.5 m/s | 보름달 배율 밖 |
| 게으름냥 기상 질주 최대 시간 | 6초 | 도착하면 먼저 끝남 |
| 게으름냥 잠든 채 피격 피해 | ×2 | |
| 사냥꾼냥 덮치기 발동 거리 | 예측 착지점 4m 안 | M3 측정으로 조정. 5일째 판당 덮치기 2회 미만이면 4.5m |
| 사냥꾼냥 덮치기 준비 시간 | 0.5초 | 마지막 0.2초에 착지 표시 고정 |
| 사냥꾼냥 도약 시간 / 거리 | 0.3초 / 최대 5m | |
| 사냥꾼냥 착지 판정 반경 | 1.2m | 잡힘 판정 0.8m와 따로 |
| 사냥꾼냥 덮치기 쿨타임 | 3초 | |
| 사냥꾼냥 헛디딤 | 1.0초 | |
| 사냥꾼냥 공놀이 | 3초 | |

모든 값은 초기값이며 인스펙터에서 조절한다. 플레이테스트 후 확정한다.

## 4. 근거

- 반응표로 구분 (D-042): 메시 하나로 3종을 만들기 때문에 차이는 행동에서 나와야 한다. 표 한 장이면 플레이어가 도움말 3줄로 배운다.
- 호기심냥 체력 3 = 컵(2) + 선풍기(1). 함정 조합을 처음 배우는 상대다.
- 게으름냥 잠든 채 피격 ×2: 잠든 게으름냥은 컵 한 번에 4를 받고 한 번 더 맞으면 퇴장한다. 깨어 있으면 3번 맞아야 한다. 대신 기절 없이 바로 스위치로 질주한다. 낙하 중심에서 스위치까지 6m를 약 1.1초에 오므로, 누른 뒤 낙하까지 1.0초를 더해 약 2.1초 안에 스위치를 떠나야 한다.
- 게으름냥 귀가: 깬 게으름냥이 계속 돌아다니면 '잠'이라는 열쇠가 사라진다. 20초 무소음 재수면 대신 목표가 끝나면 귀가해 잠든다.
- 게으름냥 질주 목표 고정: 질주 중 소리로 목표가 바뀌면 달리는 쥐가 질주하는 게으름냥을 끌고 다닐 수 있다.
- 기상 질주 5.5 = 쥐 달리기 5.5 (D-038): 깨우는 것 자체가 벌이다. 보름달을 곱하면 6.05가 되어 달리기보다 빨라지므로 곱하지 않는다.
- 전용 기상음: 추적 시작과 증원 입장의 경보음과 같으면 가장 치명적인 사건인 기상을 귀로 구분할 수 없다.
- 사냥꾼냥 잔상 무시 (D-038): 대시 반응 대신 '속지 않는 고양이'로 둔다. 추적을 끊는 열쇠는 공과 헛디딤이다.
- 예측 착지점으로 발동: 쥐가 같은 움직임을 이어 가면 착지점은 늘 사거리 5m 안(여유 1m)이다. 빗나감은 쥐가 웅크림이나 표시를 보고 움직임을 바꿨을 때만 생긴다.
- 덮치기가 나오는 쥐: 곧장 또는 옆으로 달아나는 달리기는 예측점이 4.4m(5.5 × 0.8) 앞이라 덮치지 않는다. 걷거나 멈추면 덮친다. 그래서 달리기는 덮치기를 피하는 대신 추적을 끊지 못하는 시간 벌기다.
- 착지 표시 고정 뒤 0.5초 동안: 걷다가 멈추면 2.0m, 걷다가 90° 꺾으면 약 2.8m 차이로 빗나간다. 대시하면 빗나간다. 살금살금 직진 중 멈추면 1.0m 차이라 맞으므로 꺾어야 피한다.
- 헛디딤 뒤 추적 종료: 헛디딤이 1초 쉬는 것뿐이면 사냥꾼냥 대응이 공 위치 운에 좌우된다. 끝난 뒤 조사 속도(3.5)로 움직이므로 쥐가 달려서 2m 밖을 지키면 다시 추적되지 않는다.
- 덮쳐 세운 공은 무음: 5~7일째에는 게으름냥이 2마리라, 사냥꾼냥이 공을 잡을 때마다 게으름냥이 깨면 쥐가 통제할 수 없는 사건이 된다.
- 보름달에서 사냥꾼냥 5.5 = 달리기: 곧장 달리면 간격이 그대로지만 꺾을 때마다 붙는다. 피날레에서 덮치기 회피와 공을 쓰게 하는 의도다.
