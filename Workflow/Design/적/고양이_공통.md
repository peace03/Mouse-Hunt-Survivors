# 고양이 공통

<aside>
📌

**상태:** 초안

**관련 결정:** D-011, D-013, D-017, D-018

**한 줄 요약:** 모든 고양이가 공유하는 감지·추적·잡기·기절·퇴장·재입장 규칙.

</aside>

## 1. 목표

- 고양이 반응을 플레이어가 예측할 수 있게 해서 "유인 → 위치 선점 → 작동"을 설계하게 한다.
- 데모에서 보여줄 것: 소리에 고개를 돌리고 다가오는 고양이, 함정에 맞아 기절하고 쫓겨나는 고양이.

## 2. 규칙

**감지**
- 고양이는 소음과 근접 감지로만 쥐를 찾는다. 시야는 없다.
- 소음 반경 안에 있으면 소음이 난 지점으로 조사하러 간다. 더 새로운 소음이 나면 그쪽으로 바꾼다.
- 쥐가 근접 감지 반경 안에 들어오면 소음과 관계없이 추적한다.

**상태**
- 순찰: 맵의 순찰 지점을 무작위 순서로 돈다.
- 조사: 소음 지점으로 간다. 도착했는데 쥐가 근접 감지 반경 밖이면 잠시 두리번거린 뒤 순찰로 돌아간다.
- 추적: 쥐의 현재 위치를 따라간다. 쥐가 추적 놓침 거리 밖으로 벗어난 채 일정 시간 새 소음이 없으면 마지막 위치를 조사한다.
- 미끼 먹기: 미끼 치즈를 먹는 동안 멈춘다 (→ [치즈 던지기](../플레이어/치즈_던지기.md)).
- 기절: 아무것도 하지 않는다. 기절 중에도 함정에 다시 맞는다.

**잡기**
- 쥐가 잡힘 판정 거리 안에 들어오면 잡는다 (→ [체력](../플레이어/체력.md)).
- 잡은 고양이는 잠시 멈춘다.

**퇴장과 재입장**
- 함정 피해로 체력이 0이 되면 퇴장한다. 쓰러지지 않고 가장 가까운 고양이 출입구로 달려 나간다 (→ [맵](../월드/거실_주방_맵.md)).
- 퇴장하는 순간 그 자리에 큰 치즈를 떨어뜨린다 (→ [경험치·레벨업](../성장/경험치_레벨업.md)).
- 퇴장한 고양이는 재입장 대기 뒤 같은 종류로 출입구에서 다시 들어온다. 체력은 가득 찬다.
- 퇴장 중인 고양이는 쥐를 잡지 않고 함정에도 맞지 않는다.

## 3. 수치

| 항목 | 값 |
|---|---|
| 순찰 속도 | 2.5 m/s |
| 조사 이동 속도 | 3.5 m/s |
| 추적 속도 | 종류별 (→ [고양이 종류](고양이_종류.md)) |
| 근접 감지 반경 | 2m |
| 조사 지점 두리번 시간 | 2초 |
| 추적 놓침 거리 / 시간 | 6m / 4초 |
| 잡힘 판정 거리 | 0.8m |
| 잡은 뒤 멈춤 | 1초 |
| 퇴장 이동 속도 | 7 m/s |
| 재입장 대기 | 20초 |

모든 값은 초기값이며, 플레이테스트 후 확정한다.

## 4. 근거

- 시야 없음 (D-018): 컨셉이 "소음으로 속인다"다. 감지 규칙이 소음 하나여야 플레이어가 반응을 예측하고 유인을 설계할 수 있다.
- 근접 감지 2m = 살금살금 소음 2m: 고양이 바로 옆은 살금살금으로도 위험하다. 스텔스의 긴장을 남긴다.
- 조사 3.5 < 걷기 4.0: 걸으며 소음을 내도 거리를 유지할 수 있어서 "소리 내며 끌고 다니기"가 가능하다.
- 재입장 (D-013): 고양이가 줄면 후반 긴장과 경험치 공급이 함께 끊긴다. 쫓아내기는 "20초 숨 돌릴 틈을 버는 것"이 된다.
- 퇴장 속도 7: 쫓겨나는 연출을 짧게 끝내고, 쥐 달리기(6.5)보다 빨라 퇴장 고양이를 쫓아갈 일이 없게 한다.

## 5. 연출·피드백

| 시점 | 화면 | 소리 | 애니메이션 |
|---|---|---|---|
| 소음 감지 | 머리 위 작은 "?" | 귀 쫑긋 소리 | Idle → 걷기 |
| 추적 시작 | 머리 위 "!" | 야옹 | 달리기 |
| 잡기 | - | 야옹 | 덮치기 |
| 기절 | 머리 위 별 빙글 | 띵 | 기절 |
| 퇴장 | 놀라 튀어오른 뒤 출입구로 질주, 큰 치즈 떨어짐 | 놀란 울음 | 퇴장 |
| 재입장 | 출입구에서 등장 | 작은 방울 소리 | 걷기 |

## 6. 연관 기능

- [체력](../플레이어/체력.md): 잡으면 하트 감소
- [함정 공통](../함정/함정_공통.md): 피해·기절·밀림을 받는다
