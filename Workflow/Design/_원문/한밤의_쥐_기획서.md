# 기획 초기안: 「한밤의 쥐」(가제)

> 싸우지 않고 속인다. 소음으로 고양이를 끌어들이고, 집안 물건으로 쫓아내는 쥐 서바이벌

---

## 1. 기획 개요

| 항목 | 내용 |
|---|---|
| 장르 | 스텔스 + 함정 + 서바이벌 (뱀서식 레벨업 구조) |
| 플랫폼 / 엔진 | PC, 모바일 / Unity (URP) |
| 시점 | 쿼터뷰 (약 50~55도), 쥐를 따라가는 카메라 |
| 플레이 타임 | 한 판 5분 (게임 내 시간 밤 12시 → 아침 6시) |
| 한 줄 피치 | 싸우지 않고 속인다. 소음으로 고양이를 끌어들이고, 집안 물건으로 쫓아내는 쥐 서바이벌 |
| 승리 / 패배 | 아침 6시까지 생존 / 하트 3개 소진 |

---

## 2. 핵심 시스템

### 2.1 이동과 소음

| 상태 | 입력 | 이동속도 | 소음 반경 |
|---|---|---|---|
| 살금살금 | 조이스틱 약하게 | 2.0 | 2m |
| 걷기 | 보통 | 4.0 | 5m |
| 달리기 | 끝까지 밀기 | 6.5 | 9m |
| 대시 | 버튼 (쿨 4초) | 순간 이동 | 9m |

- 소음 반경은 쥐 발밑에 **원형 표시**로 보여줍니다.
- 반경 안의 고양이는 쥐의 위치(소음 발생 지점)로 이동합니다.
- 수치는 초안이며, 1일차 플레이 테스트로 조정합니다.

### 2.2 치즈

- **미끼:** 던진 지점에 반경 6m의 소음을 발생시키고, 고양이가 도착하면 3초간 먹느라 멈춥니다.
- **경험치:** 쫓겨난 고양이가 치즈 조각을 떨어뜨리고, 줍으면 경험치가 됩니다.
- **레벨업:** 한 판에 6~8번 정도 레벨업하도록 필요량을 설계합니다. 레벨업 시 3택1입니다.

### 2.3 함정과 상호작용

- 함정 근처에서 상호작용 버튼을 누르면 작동합니다.
- 각 함정에는 쿨타임이 있습니다.
- 고양이가 함정 범위에 있을 때 작동시켜야 하므로, **유인 → 위치 선점 → 작동**이 핵심 플레이입니다.

### 2.4 체력

- 하트 3개입니다. 고양이에게 잡히면 하트가 1개 줄고, 1.5초 무적 후 쥐가 튕겨 나갑니다.
- 고양이는 쓰러지지 않고 **집 밖으로 쫓겨나는** 연출로 처리합니다. 귀여운 톤이 유지됩니다.

---

## 3. 콘텐츠

### 3.1 함정 3종

| 함정 | 위치 | 효과 | 쿨타임 |
|---|---|---|---|
| 컵 밀기 | 식탁 / 선반 가장자리 | 낙하 지점 반경 3m 기절 4초 + 피해 2 | 20초 |
| 로봇청소기 | 거실 바닥 충전독 | 8초간 경로 이동, 닿으면 밀려나고 기절 2초 | 25초 |
| 선풍기 | 소파 옆 | 10초간 바람, 고양이를 뒤로 밀어 함정 위치로 보냄 | 18초 |

### 3.2 고양이 3종 (+선택 보스)

| 고양이 | 체력 | 행동 |
|---|---|---|
| 호기심냥 | 3 | 소음, 던진 치즈에 가장 먼저 반응하는 미끼 전용 |
| 게으름냥 | 5 | 평소엔 수면, 큰 소음(달리기 이상)에 기상 후 빠르게 추적 |
| 사냥꾼냥 | 4 | 소음이 작아도 접근, 대시 타이밍을 읽고 덮침 |
| (선택) 대왕냥 | 12 | 4분 30초 등장, 돌진 + 발톱 휘두르기 |

### 3.3 시간대별 진행

| 시각 (게임 내) | 실제 시간 | 상황 |
|---|---|---|
| 12시~1시 | 0:00~ | 게으름냥 2마리 수면, 호기심냥 1마리 순찰 |
| 2시~3시 | 1:00~ | 호기심냥 추가, 순찰 고양이 증가 |
| 3시~4시 | 2:00~ | 사냥꾼냥 1마리 등장 |
| 4시~5시 | 3:00~ | 사냥꾼냥 2마리, 동시 고양이 6마리 이상 |
| 5시~6시 | 4:00~ | 전원 활성화, 창밖이 밝아지며 긴장 고조 (선택: 대왕냥) |

### 3.4 업그레이드 (목표 16개)

- **함정 강화 (6):** 쿨타임 감소, 범위 증가, 기절 시간 증가 (함정별)
- **쥐 능력 (5):** 살금살금 속도, 소음 반경 감소, 대시 쿨타임 감소, 하트 +1, 피격 후 무적 시간 증가
- **치즈 (3):** 던지기 사거리, 미끼 지속시간, 흡수 범위
- **시너지 (2):** 선풍기 바람 맞은 고양이는 컵 피해 2배, 청소기 경로에 치즈 흔적 생성

## 4. 3일 일정 (Unity)

| 일차 | 목표 |
|---|---|
| **0일차 (지금)** | 모델링 (아래 10번 작업 순서대로) |
| **1일차** | 쥐 이동 + 소음 반경, 고양이 1종 AI(소음 반응), 컵 함정 1개, 치즈 던지기, 치즈 → 레벨업 → 3택1 UI |
| **2일차** | 나머지 함정 2종, 고양이 3종 행동, 업그레이드 16개, 시간 진행표 적용, 하트/게임오버/클리어 |
| **3일차** | 시간대별 조명 변화, 이펙트, 효과음/BGM, 밸런스 3~4판, 빌드 |

**스코프 컷 순서:** 대왕냥 → 시너지 업그레이드 → 선풍기 순으로 먼저 뺍니다.

# 아트 디렉션 (모델링용)

## 5. 디자인 스타일

**스타일: 로우폴리 + 파스텔톤 + 따뜻한 야간 조명 (미니어처 디오라마 느낌)**

- **형태:** 둥글고 통통한 실루엣에 단순한 면 처리입니다. 텍스처는 단색에 가까운 컬러와 약한 그라데이션 정도로 합니다. AI 3D 생성과 직접 제작을 섞어도 톤이 맞춰지기 쉽습니다.
- **분위기:** 무섭기보다 **아기자기한 장난감 집에 몰래 들어온 쥐** 느낌입니다.
- **조명:** 달빛(푸른색) + 창밖 가로등(주황) + 스탠드 불빛으로 구성하고, 시간이 지나면 창에서 따뜻한 아침빛이 들어옵니다.

### 컬러 팔레트

| 용도 | 색상 |
|---|---|
| 밤 분위기 베이스 | 남색 `#2B3A67`, 보라 `#5B5F97` |
| 바닥 / 가구 | 따뜻한 베이지 `#E6C9A8`, 갈색 `#A67B5B` |
| 쥐 | 회색 `#B8B8C0`, 귀/코 핑크 `#F4A6B0` |
| 치즈 / 상호작용 포인트 | 노랑 `#FFD23F` (**함정과 치즈에만** 사용해 눈에 띄게) |
| 위험 (사냥꾼냥, 경고 표시) | 붉은 주황 `#E4572E` |

---

## 6. 메인 캐릭터: 쥐

- **이름(가제):** 치즈 (또는 "모찌")
- **체형:** 통통한 3등신, 큰 귀, 작은 몸, 가는 꼬리. 서 있는 자세가 아닌 **네발 자세**로 만듭니다 (쿼터뷰에서 실루엣이 잘 보임).
- **디테일:** 큰 동그란 눈, 분홍 코와 귀 안쪽, 꼬리 끝에 작은 컬러 포인트로 식별성을 확보합니다.
- **표정/모션:**
  - 살금살금: 몸을 낮추고 귀를 눕힘
  - 달리기: 귀가 펄럭이고 꼬리가 올라감
  - 피격: 놀란 눈, 털이 곤두섬
  - 치즈 먹기: 볼이 빵빵해짐
- **모델링 사양:** 3,000~5,000 tris, 리깅은 몸통 / 머리 / 귀 2 / 꼬리 3~4마디 정도의 간단 본으로 충분합니다.
- **애니메이션 필수 (7개):** Idle, 살금살금, 달리기, 대시, 피격, 던지기, 상호작용

---

## 7. 고양이 디자인 (성격이 실루엣으로 구분되게)

| 고양이 | 외형 | 색 | 식별 포인트 |
|---|---|---|---|
| 호기심냥 | 둥근 얼굴, 큰 눈, 중간 체형 | 크림색 | 머리 위 물음표 이펙트, 꼬리 살랑 |
| 게으름냥 | 큰 뚱뚱한 체형, 반쯤 감은 눈 | 회색 + 줄무늬 | 수면 시 "Zzz" 이펙트, 웅크린 자세 |
| 사냥꾼냥 | 날렵한 체형, 날카로운 눈 | 검정 | 붉은 눈빛, 낮은 자세로 접근 |
| (선택) 대왕냥 | 일반 고양이의 약 2배 크기 | 주황 + 흉터 | 큰 덩치, 발톱 |

- **스케일:** 쥐 몸길이를 1로 잡으면 고양이는 약 4~5배입니다 (쥐가 압도되는 느낌).
- **사양:** 4,000~6,000 tris.
- **애니메이션 (6개):** Idle, 걷기, 달리기, 덮치기, 기절, 퇴장. 3종이 **같은 본 구조를 공유**하게 하면 작업량이 크게 줄어듭니다.

## 8. 배경: 거실 + 주방이 이어진 집 한 칸

### 공간 구성 (위에서 본 배치)

```
┌──────────────────────────────────────┐
│ [창문]            [창문]       [냉장고] │
│ 소파 + 선풍기     러그        주방 싱크  │
│  │                           식탁+의자 │
│ TV장            쥐구멍 ②                │
│ 충전독(청소기)     (중앙 공터)    쥐구멍 ① │
└──────────────────────────────────────┘
```

- **크기:** 쥐 기준 약 40m × 30m (쿼터뷰에서 화면 2~3개 분량)
- **구조:** 벽 2면만 모델링합니다 (카메라 쪽 벽은 없음, 디오라마 방식). 모델링 부담이 크게 줄어듭니다.
- **바닥:** 나무 바닥에 러그 1개로 구역을 구분해 동선 가독성을 확보합니다.
- **동선 설계:** 가구 사이를 지나는 길과 공터가 번갈아 나와야 고양이 유인과 도망 플레이가 생깁니다.

## 9. 소품 리스트 (우선순위순)

### A. 기능 소품 (게임플레이에 필요, 최우선)

| 소품 | 용도 | 사양 |
|---|---|---|
| 컵 + 식탁 | 컵 밀기 함정 | 컵은 별도 오브젝트 (낙하 애니메이션) |
| 로봇청소기 + 충전독 | 청소기 함정 | 둥근 본체, 빛나는 센서 |
| 선풍기 | 선풍기 함정 | 날개가 회전하는 분리된 메쉬 |
| 쥐구멍 (벽 아래 2~3곳) | 시작 지점 / 연출 | 아치형 구멍 + 작은 치즈 표지 |
| 치즈 조각 | 경험치 아이템 | 삼각형 치즈, 노랑, 빛나는 효과 |

### B. 구조 소품 (공간 구성, 2순위)

식탁 + 의자 2개, 소파, TV장, 러그, 냉장고, 주방 싱크대, 창문 2개 (달빛과 아침빛 연출용)

### C. 장식 소품 (시간 남을 때만)

화분, 책장 + 책 몇 권, 스탠드 조명, 쿠션, 고양이 밥그릇, 고양이 장난감 공 (이것들을 소음 오브젝트로 쓰는 확장 가능)

### 에셋 활용 팁

- B와 C는 **Kenney 무료 팩이나 Unity Asset Store 무료 로우폴리 가구**로 대체해도 됩니다. 단, A(기능 소품)와 쥐/고양이는 직접 만들어야 톤이 맞습니다.
- AI 3D 생성 도구(Meshy, Tripo 등)로 소품을 뽑을 경우, 프롬프트에 `low poly, pastel color, rounded shapes, toy-like`를 공통으로 넣으면 톤이 비슷하게 나옵니다. 생성 후 폴리 수 줄이기와 피벗 위치 정리가 필요합니다.

## 10. 모델링 작업 순서 (추천)

1. 쥐 (메인 캐릭터, 가장 먼저 완성해서 스타일 기준 확정)
2. 고양이 1종 (호기심냥) → 나머지는 변형으로 제작
3. 기능 소품 5종 (컵, 청소기, 선풍기, 쥐구멍, 치즈)
4. 구조 소품 (식탁, 소파, 러그, 벽, 바닥)
5. 장식 소품

**폴리 가이드:** 캐릭터 3천~6천 tris, 기능 소품 500~2천, 장식 소품 200~800 tris입니다. 고양이가 동시에 6~8마리 나오므로 고양이 쪽 폴리 수는 늘리지 않는 게 좋습니다.
