## 1. 목표

- 가구 사이 길과 공터가 번갈아 나와 유인과 도망이 모두 가능한 동선을 만든다.
- PC에서는 방 전체를 한 화면에 보여 준다. 고양이 상태, 소리 원, 함정 범위를 한눈에 읽고 다음 수를 정한다.
- 가구는 옮기지 않는다. 밤의 차이는 고양이 구성·함정·규칙 데이터로 만든다 (D-029).

## 2. 규칙

**배치 (위에서 본 그림)**

```
┌──────────────────────────────────펫도어──────┐
│ [창문]              [창문]           [냉장고] │
│ 소파 + 선풍기        러그      주방 조리대(컵 B) │
펫도어                               식탁(컵 A)    │
│ TV장 + 충전독    쥐구멍 ②   공 시작 자리         │
│                  (중앙 공터)          쥐구멍 ①  │
└────────────────────────────────────────────┘
```

- 벽은 2면(위·왼쪽)만 만든다. 카메라 쪽 벽은 없다 (디오라마 방식).
- 바닥은 나무, 러그 1개로 구역을 나눈다.
- 가구는 쥐와 고양이 모두 지나갈 수 없는 장애물이다. 쥐만 지나가는 가구 밑 통로는 없다.
- 가구 배치는 밤과 추위 단계에 따라 바뀌지 않는다.

**쥐와 고양이**
- 쥐는 쥐구멍 ②(중앙)에서 시작한다. 쥐구멍 ②는 모찌 가족이 사는 곳이다. 쥐구멍에 숨는 기능은 없다.
- 고양이 출입구는 펫도어 2곳이다: 거실 왼쪽 벽, 주방 쪽 위 벽. 벽이 없는 아래·오른쪽에는 두지 않는다. 고양이는 여기로 들어오고 퇴장한다.
- 게으름냥 수면 지점은 2곳이다. 게으름냥 슬롯 순서대로 1곳씩 배정한다 (수면·귀가 규칙 → [고양이 종류](../적/고양이_종류.md)).
- 수면 지점은 레이아웃 자동 검사 2를 통과하는 자리에 둔다. 러그 위와 소파 앞은 청소기 경로와 선풍기 바람에 겹치므로 쓰지 않는다.
- 순찰 지점은 방 전체에 8곳 안팎이다.
- M0 측정에서 스위치 근처 버티기가 루프보다 유리하면 각 스위치 3m 안에 순찰 지점을 1곳씩 더한다 (측정 방법 → [디버그](../디버그/디버그.md)).

**함정과 스위치**
- 모든 스위치는 효과 범위 밖에 있다 (공통 규칙 → [함정 공통](../함정/함정_공통.md)).
- 컵: 1개. 낙하 위치는 A 식탁(기본)과 B 주방 조리대 2곳이고, 한 판에 한 곳만 켠다. B는 v1.1 추위 판에서만 쓴다 (켜는 규칙 → [캠페인](../진행/캠페인.md)).
- 컵 스위치는 낙하 중심에서 식탁(조리대) 반대편 바닥에 둔다. A와 B의 스위치 거리는 같다 (→ [컵 밀기](../함정/컵_밀기.md)).
- 로봇청소기: 충전독은 TV장 아래에 있다. 충전독이 스위치이고 경로의 첫 지점이다.
- 청소기 경로는 하나다: 충전독 → 중앙 공터 → 쥐구멍 ② 앞 → 러그 → 소파 앞 → 충전독으로 도는 고리 (→ [로봇청소기](../함정/로봇청소기.md)).
- 선풍기: 소파 옆. 청소기 경로의 소파 앞 구간을 향한다. 스위치는 본체 뒤에 있고 충전독에서 걸어서 갈 수 있는 거리 안에 둔다 (→ [선풍기](../함정/선풍기.md)).

**장난감 공**
- 시작 자리는 거실 중앙 공터 1곳이다. 4일째 밤부터 놓인다 (→ [장난감 공](장난감_공.md)).
- 시작 자리는 레이아웃 자동 검사 3을 통과하는 자리에 둔다. 시작 자리에서 한 번 차서 컵 A 범위 안에 공을 세울 수 있는 방향이 하나 이상 있어야 한다.

**그 밖의 지점**
- 밥그릇: 주방 냉장고 앞. 설정을 보여 주는 소품이며 기능과 연출은 없다 (→ [스토리](../진행/스토리.md)).
- 부스러기 생성 지점: 가구 사이 길과 공터에 15곳 안팎. 함정 범위와 겹치는 곳을 일부 포함한다.

**배치 검사**
- 모든 배치(컵 A·B, 충전독, 청소기 경로, 선풍기, 수면 지점, 공 시작 자리, 순찰 지점)는 레이아웃 자동 검사 1~6을 통과해야 한다 (검사 목록 → [디버그](../디버그/디버그.md)).

**카메라**
- PC: 방 전체가 한 화면에 보이는 고정 직교 카메라. 쥐를 따라가지 않는다.
- 모바일: 쥐를 중심으로 확대해 따라간다. 두 손가락 입력으로 방 전체 보기(PC와 같은 화면)와 확대 보기를 오간다 (모바일 범위와 일정 → [프로젝트](../00_프로젝트.md)).

- 좌표: 게으름냥 수면 지점 2곳, 공 시작 자리, TV장·충전독, 선풍기 스위치, 컵 A·B 스위치는 구현할 때 AI가 레이아웃 자동 검사(→ [디버그](../디버그/디버그.md))를 통과하는 자리로 정하고 이 문서에 기록한다 (D-056).

## 4. 근거

- 배치·디오라마 방식·동선 원칙은 원문을 따른다.
- 26×20m, 고정 카메라: 구현된 크기다. 맵을 키우면 길찾기 영역과 씬 생성, 테스트를 다시 만들어야 한다. 대신 쥐 몸 소리에만 곱하는 전역 소음 배율로 방 크기에 맞춘다 (→ [기본조작](../플레이어/기본조작.md)).
- PC 방 전체 고정: 이 게임은 방 전체의 소리와 고양이 상태를 읽고 동선을 짜는 게임이다. 따라가는 카메라는 화면 밖 고양이를 숨긴다.
- 모바일만 확대·따라가기: 폰 화면에서 방 전체를 보이면 고양이가 너무 작다. PC 설계는 그대로 두고 폰의 가독성만 따로 푼다 (D-050).
- 고양이 출입구 (D-013): 퇴장과 재입장에 필요하다. 거실과 주방 양쪽에 두어 한쪽으로만 몰리지 않게 했다.
- 가구 밑 통로 없음 (D-025): 고양이가 못 들어오는 안전지대가 생기면 소리 관리의 긴장이 사라진다.
- 청소기 경로가 쥐구멍 ② 앞을 지난다 (D-025): 처음 하는 사람도 시작 지점에서 경로를 자연스럽게 본다. 경로를 하나로 두어 충전독과 검증 조합이 늘지 않는다.
- 선풍기 방향 (D-024): 원문 자리(소파 옆)를 지키고, 가까운 청소기 경로로 고양이를 밀어 넣는 연계를 만든다.
- 수면 지점을 함정 범위·청소기 경로·선풍기 바람에서 뗀다: 잠든 게으름냥이 함정이나 바람에 닿아 깨면 쥐가 선 스위치로 질주한다. 쥐가 통제할 수 없는 기상을 배치에서 없앤다.
- 컵 B: 추위 판에서만 낙하 위치를 바꿔 같은 밤을 다시 풀게 한다. 가구를 옮기지 않으므로 길찾기 영역은 하나로 충분하다.
