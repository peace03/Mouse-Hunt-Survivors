# 거실·주방 맵

<aside>
📌

**상태:** 초안

**관련 결정:** D-011, D-013, D-017, D-020, D-024, D-025

**한 줄 요약:** 거실과 주방이 이어진 집 한 칸. 함정·출입구·생성 지점의 배치와 카메라.

</aside>

## 1. 목표

- 가구 사이 길과 공터가 번갈아 나와 유인과 도망이 모두 가능한 동선을 만든다.

## 2. 규칙

**배치 (위에서 본 그림)**

```
┌──────────────────────────────────────┐
│ [창문]            [창문]       [냉장고] │
│ 소파 + 선풍기     러그        주방 싱크  │
│  │                           식탁+의자 │
│ TV장            쥐구멍 ②                │
│ 충전독(청소기)     (중앙 공터)    쥐구멍 ① │
└──────────────────────────────────────┘
```

- 벽은 2면(위·왼쪽)만 만든다. 카메라 쪽 벽은 없다 (디오라마 방식).
- 바닥은 나무, 러그 1개로 구역을 나눈다.
- 쥐는 쥐구멍 ②(중앙)에서 시작한다. 쥐구멍 ②는 모찌 가족이 사는 곳이고 배웅·맞이 연출이 여기서 나온다 (→ [스토리](../진행/스토리.md)). 쥐구멍에 숨는 기능은 없다.
- 고양이 출입구는 펫도어 2곳이다: 거실 왼쪽 벽, 주방 오른쪽 벽. 고양이는 여기로 들어오고 퇴장한다.
- 함정: 컵(식탁, 1개), 로봇청소기(TV장 아래 충전독), 선풍기(소파 옆).
- 선풍기는 청소기 경로의 소파 앞 구간을 향한다 (→ [선풍기](../함정/선풍기.md)).
- 청소기 경로: 충전독 → 중앙 공터 → 쥐구멍 ② 앞 → 러그 → 소파 앞 → 충전독으로 도는 고리 (→ [로봇청소기](../함정/로봇청소기.md)).
- 밥그릇: 주방 냉장고 앞. 승리 연출에서 고양이들이 달려가는 곳이다.
- 순찰 지점: 방 전체에 8곳 안팎.
- 부스러기 생성 지점: 가구 사이 길과 공터에 15곳 안팎. 함정 범위와 겹치는 곳을 일부 포함한다.
- 게으름냥 수면 위치: 러그 위, 소파 앞 바닥 2곳.
- 가구는 쥐와 고양이 모두 지나갈 수 없는 장애물이다. 쥐만 지나가는 가구 밑 통로는 없다.

**카메라**
- 쿼터뷰, 내려다보는 각도 약 50~55도, 쥐를 따라간다.
- 쥐가 화면 가운데에 오도록 부드럽게 따라간다.

## 3. 수치

| 항목 | 값 |
|---|---|
| 맵 크기 | 40m × 30m |
| 카메라 각도 | 52° |
| 카메라 거리 | 18m |
| 카메라 따라가기 지연 | 0.15초 |

모든 값은 초기값이며, 플레이테스트 후 확정한다.

### 소품 (우선순위순)

**A. 기능 소품 (최우선, 직접 제작)**

| 소품 | 용도 | 사양 |
|---|---|---|
| 컵 + 식탁 | 컵 밀기 함정 | 컵은 별도 오브젝트 (낙하 애니메이션) |
| 로봇청소기 + 충전독 | 청소기 함정 | 둥근 본체, 빛나는 센서 |
| 선풍기 | 선풍기 함정 | 날개가 회전하는 분리된 메쉬 |
| 쥐구멍 (벽 아래 2~3곳) | 시작 지점 / 연출 | 아치형 구멍 + 작은 치즈 표지 |
| 치즈 조각 | 경험치 아이템 | 삼각형 치즈, 노랑, 빛나는 효과 |

**B. 구조 소품 (2순위, 무료 에셋 대체 가능)**: 식탁 + 의자 2개, 소파, TV장, 러그, 냉장고, 주방 싱크대, 창문 2개 (달빛과 아침빛 연출용), 펫도어 2개, 고양이 밥그릇 (승리 연출)

**C. 장식 소품 (시간 남을 때만)**: 화분, 책장 + 책 몇 권, 스탠드 조명, 쿠션, 고양이 장난감 공

## 4. 근거

- 배치·크기·디오라마 방식·동선 원칙은 원문 그대로다.
- 고양이 출입구 (D-013): 원문 그림에 없지만 퇴장과 재입장에 필요하다. 거실과 주방 양쪽에 두어 한쪽으로만 몰리지 않게 했다.
- 가구 밑 통로 없음 (D-025): 고양이가 못 들어오는 안전지대가 생기면 소음 관리의 긴장이 사라진다.
- 청소기 경로가 쥐구멍 ② 앞을 지난다 (D-025): 처음 하는 사람도 시작 지점에서 경로를 자연스럽게 본다.
- 선풍기 방향 (D-024): 원문 자리(소파 옆)를 지키고, 가까운 청소기 경로로 고양이를 밀어 넣는 연계를 만든다.
- 카메라 수치: 원문 각도 범위의 가운데. 거리 18m는 40m 맵에서 화면 2~3개 분량이 되도록 잡은 값이다.
