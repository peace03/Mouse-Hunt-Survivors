# 프로젝트: 한밤의 쥐 (가제)

<aside>
📌

**상태:** 초안

**관련 결정:** D-001, D-002, D-003, D-004, D-005, D-009, D-010, D-011, D-026, D-027, D-029, D-035, D-036, D-047, D-049, D-050, D-051, D-052, D-054, D-060

**한 줄 요약:** 싸우지 않고 속인다. 소리로 고양이를 함정 범위로 데려오고, 범위 밖 스위치로 맞힌 뒤 빠진다. 쫓아낼수록 아침이 빨리 온다.

## 1. 목표

| 항목 | 내용 |
|---|---|
| 이름 | 「한밤의 쥐」(가제). 저장소 이름 `MouseHuntSurvivors`는 유지 |
| 장르 | 스텔스 + 함정 + 서바이벌 (뱀서식 레벨업 구조) |
| 핵심 재미 | 소리로 고양이를 함정 범위에 세우고, 범위 밖 스위치를 눌러 맞힌 뒤 자리를 뜨는 "유인 → 위치 선점 → 작동 → 빠지기" |
| 시점 | PC는 방 전체가 보이는 고정 직교 카메라. 모바일만 쥐 중심 확대·따라가기 ([맵](월드/거실_주방_맵.md)) |
| 한 판 | 게임 시계 12:00 → 6:00, 5단계. 고양이를 쫓아낼 때마다 아침이 앞당겨진다 ([시간 진행](진행/시간_진행.md)) |
| 반복 구조 | 캠페인 7밤 + 겨울 창고, v1.1에서 기록 모드(추위, 끝없는 밤) ([캠페인](진행/캠페인.md), [겨울 창고](성장/겨울_창고.md)) |
| 승리 / 패배 | 아침 6시까지 생존 / 하트 모두 잃음 |
| 장기 목표 | 일반 플레이어 중앙값 5~8시간의 완결형 + 기록 모드 |

### 기둥

1. **소리가 곧 규칙이다.** 모든 감지는 소리와 근접 2m로만 한다. 시야와 흔적 따라가기는 없다 (D-018).
2. **고양이마다 열쇠는 하나다.** 종류의 차이는 체력·속도가 아니라 도구에 어떻게 반응하는지다. 추적을 끊는 것도 그 열쇠다. 호기심냥은 미끼, 게으름냥은 잠, 사냥꾼냥은 공.
3. **누르는 자리와 맞히는 자리는 다르다.** 모든 함정 스위치는 효과 범위 밖에 있다. 누르면 쥐 자리에서 소리가 나고, 맞은 고양이는 스위치로 온다.
4. **쫓아내면 아침이 온다.** 숨어 버티면 살 수는 있지만 아침이 늦고 별 3을 못 얻는다.
5. **새 모델 대신 데이터로 늘린다.** 같은 거실·주방(D-029), 같은 고양이 메시를 쓴다. 밤·규칙·배치·추위는 데이터다.

### 일정이 밀리면 버리는 순서

1. 끝없는 밤
2. 컵 위치 무작위 (추위도 고정 배치)
3. 추위 2~3단계 (추위 1만 남김)
4. 그림자 대시 진화
5. 선풍기: 6일째를 '청소기와 공, 컵 고장'으로 바꾸고 부탁을 교체하며, 바람 카드 2장을 지운다.
6. 사냥꾼냥 예측 덮치기: '미끼를 무시하고 공을 쫓는 빠른 고양이'로 줄인다. 이때는 잔상이 사냥꾼냥의 추적도 끊는다.

**버리지 않는 것:** M0 규칙 수선, 아침 당김, 반응표의 핵심(미끼·잠·공), 원기록 저장, 부탁 판정.

### 외부 플레이테스터

- 온라인으로 소수(3~5명)를 모집한다. itch.io 같은 곳의 비공개 링크로 빌드를 준다.
- 1차는 M2 빌드(1~4일째), 2차는 M5 빌드(5~7일째)다. 같은 사람이어도 된다.
- 판정 방법과 기준(밤별 밸런스 목표, 테스터가 없을 때)은 [캠페인](진행/캠페인.md)에 있다.

## 4. 근거

- 2026-10-21 재설계에서 '리소스 최소화' 안이 우승했다. 고양이를 생김새가 아니라 반응으로 구분하면 메시 1개로 3종을 만든다.
- PC 카메라는 방 전체를 보며 소리를 읽는 설계라 고정한다. 폰에서는 고양이가 너무 작아 보여 모바일만 확대·따라가기로 따로 푼다.
- 맵 하나, 고양이 3종으로 30시간을 채우려면 큰 확장이 필요하다. 그래서 5~8시간 완결형에 상한 없는 기록을 더한다.
- 외부 테스터는 난이도가 개발자 실력에 맞춰지는 편향을 줄인다. 판정 방식의 근거는 [캠페인](진행/캠페인.md)에 있다.
- 추위를 3단계로 묶어 검증할 설정을 28개로 제한한다. 반응을 보고 데이터로 늘린다.
- 7밤 개발자 5판 한 바퀴는 35판 × 판당 약 5분 = 약 3시간이다.
