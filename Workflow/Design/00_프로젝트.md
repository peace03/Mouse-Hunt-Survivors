# 프로젝트: 한밤의 쥐 (가제)

> 싸우지 않고 속인다. 소음으로 고양이를 끌어들이고, 집안 물건으로 쫓아내는 쥐 서바이벌.

## 1. 개요

| 항목 | 내용 |
|---|---|
| 이름 | 「한밤의 쥐」(가제). 저장소 이름 `MouseHuntSurvivors`는 유지 |
| 장르 | 스텔스 + 함정 + 서바이벌 (뱀서식 레벨업 구조) |
| 핵심 재미 | 소음으로 고양이를 끌어 함정 범위에 세우고, 위치를 선점해 작동시키는 "유인 → 위치 선점 → 작동" |
| 시점 | 쿼터뷰 (약 50~55도), 쥐를 따라가는 카메라 |
| 한 판 | 5분 (게임 내 밤 12시 → 아침 6시) |
| 승리 / 패배 | 아침 6시까지 생존 / 하트 모두 잃음 |

## 2. 기술

| 항목 | 내용 |
|---|---|
| 엔진 | Unity 6000.6.0f1, URP |
| Unity 프로젝트 위치 | 저장소 하위 `MidnightMouse/` |
| 플랫폼 | PC (Windows) + 모바일 |
| 목표 프레임 | PC 144FPS (프레임당 6.9ms) |
| 단위 | 기획서의 1m = Unity 1unit |
| 코드 규칙 | [코드컨벤션](../Rules/코드컨벤션.md) |

## 3. 작업 분담

| 누가 | 무엇 |
|---|---|
| 사용자 | 게임 방향·범위, 쥐·고양이·기능 소품 모델링, 플레이 판단, 통합·출시 결정 |
| AI | 허가된 작업의 기획 정리·계약·구현·검증·문서화, 실행 기록에 근거한 개선 후보 작성 |

- 모델이 준비되기 전에는 임시 도형으로 구현한다.
- 작업 방식은 [AI 운영 지침](../AI_지침.md)과 [개발·자기개선 절차](../README.md)를 따른다 (D-026).

## 4. 일정 (마감 2026-10-21)

| 일차 | 날짜 (초안) | 목표 |
|---|---|---|
| 0일차 | 10/15 ~ 10/18 | 모델링 ([작업 순서](아트/아트_디렉션.md)) |
| 1일차 | 10/19 | 쥐 이동 + 소음 반경, 고양이 1종 AI(소음 반응), 컵 함정 1개, 치즈 던지기, 치즈 → 레벨업 → 3택1 UI |
| 2일차 | 10/20 | 나머지 함정 2종, 고양이 3종 행동, 업그레이드 16개, 시간 진행표, 하트·게임오버·클리어 |
| 3일차 | 10/21 | 시간대별 조명, 이펙트, 효과음·BGM, 인트로 카드·단계 문구·첫 판 안내, 가족 배웅·맞이 연출 ([스토리](진행/스토리.md)), 밸런스 3~4판, 빌드 |

**스코프 컷 순서:** 대왕냥 → 시너지 업그레이드 → 선풍기.

## 5. 태그·레이어

Unity 설정에 등록한 뒤 `등록` 칸을 O로 바꾼다.

| 종류 | 이름 | 쓰는 곳 | 등록 |
|---|---|---|---|
| 태그 | `Player` | 쥐 (Unity 기본 태그) | O |
| 레이어 | `Player` | 쥐 | X |
| 레이어 | `Cat` | 고양이 (소음·함정 범위 검사 대상) | X |
| 레이어 | `Trap` | 함정 상호작용 지점 | X |
| 레이어 | `Pickup` | 치즈 조각 | X |
| 레이어 | `Obstacle` | 가구·벽 (길찾기 장애물) | X |

## 6. 빌드

- PC: Windows 64bit.
- 모바일: 범위 미정 (확인 필요).

## 7. 확인 필요

- 일차별 날짜: 위 표의 배치(0일차 10/15~18, 3일차 = 마감일 10/21)가 맞는지.
- 구현 시작 시점: 모델링(0일차)과 병행해 임시 도형으로 지금 구현을 시작할지. 추천: 병행.
- 모바일 목표 프레임: 144FPS는 PC 기준. 추천: 모바일 60FPS.
- 모바일 빌드를 10/21 마감 범위에 넣을지. 추천: PC 먼저, 모바일 조작 UI는 시간이 남으면.
- 가족 배웅·맞이 연출과 인트로 카드의 스코프 컷 순서. 추천: 가족 연출을 대왕냥 다음 2순위로 (빠지면 인트로 카드와 승패 문구만 남긴다).
