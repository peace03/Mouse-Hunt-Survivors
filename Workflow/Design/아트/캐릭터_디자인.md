# 캐릭터 디자인

<aside>
📌

**상태:** 초안

**관련 결정:** D-008, D-009, D-011, D-031, D-048, D-049, D-054

**한 줄 요약:** 주인공 쥐 모찌, 고양이 3종(메시 1개 + 재질 슬롯 3개), 아기 쥐의 외형과 재질, 리깅·애니메이션 목록.

</aside>

## 1. 목표

- 고정 카메라로 방 전체를 볼 때도 쥐와 고양이 종류가 색과 비율만으로 구분된다.
- 사용자 모델링은 고양이 메시 1개로 끝낸다. 종류는 재질과 비율, 소품으로 만든다.

## 2. 규칙

### 쥐: 모찌

- **모델:** 기존 쥐 모델을 쓴다.
- **체형:** 통통한 3등신, 큰 귀, 작은 몸, 가는 꼬리. 서 있는 자세가 아닌 **네발 자세** (쿼터뷰에서 실루엣이 잘 보임).
- **디테일:** 큰 동그란 눈, 분홍 코와 귀 안쪽, 꼬리 끝 작은 컬러 포인트.
- **표정·모션:**
  - 살금살금: 몸을 낮추고 귀를 눕힘
  - 달리기: 귀가 펄럭이고 꼬리가 올라감
  - 피격: 놀란 눈, 털이 곤두섬
  - 치즈 먹기 (레벨업): 볼이 빵빵해짐

### 아기 쥐

- 엔딩 카드 뒤 1컷(선택)에만 나온다 (→ [스토리](../진행/스토리.md)). 판마다 나오지 않는다.
- 2마리. 모찌 모델을 0.6배로 줄이고 몸 색만 바꿔 쓴다 (한 마리는 밝은 회색, 한 마리는 베이지). 모찌의 Idle만 쓴다.

### 고양이

- **메시 1개로 3종을 만든다.** 부품을 나눈다: 몸, 머리, 꼬리 (가능하면 다리 4개도).
- **재질 슬롯 3개:** 몸, 배·주둥이, 눈. 텍스처는 그리지 않고 슬롯마다 단색 재질을 지정한다. 줄무늬, 마스크 텍스처, 전용 셰이더는 쓰지 않는다.
- 종류는 재질 색, 몸 비율, 도형 소품으로 구분한다.

| 고양이 | 몸 | 배·주둥이 | 눈 | 비율 (기본 대비) | 소품 |
|---|---|---|---|---|---|
| 호기심냥 | 크림 | 흰색 | 검정 | 1.0배 | 방울 |
| 게으름냥 | 회색 | 연회색 | 검정 | 가로 1.25배, 높이 0.9배 | 목도리 (도형) |
| 사냥꾼냥 | 검정 | 흰색 | 붉은 발광 | 0.9배, 높이 1.05배 | 없음 |

- 상태 기호(? ! ♥ × * Zzz @)는 [고양이 공통](../적/고양이_공통.md)과 [고양이 종류](../적/고양이_종류.md)에 있다.

### 리깅과 애니메이션

- 쥐와 고양이는 리깅하고 애니메이션을 적용한다. 고양이 3종은 같은 메시라 본과 애니메이션을 함께 쓴다.
- 모델·애니메이션이 준비되기 전에는 아래 표의 코드 움직임으로 대신한다. 게임 규칙은 애니메이션을 기다리지 않는다.
- 수면과 기절은 메시를 눕히지 않는다. 눕히면 죽은 고양이처럼 보인다.
- 선풍기 날개, 장난감 공, 치즈는 코드로 움직이므로 리깅하지 않는다.

**쥐 애니메이션 (9)**

| 애니메이션 | 코드 움직임 (대체) |
|---|---|
| Idle | 없음 |
| 살금살금 | 몸을 납작하게 |
| 걷기 | 몸 흔들림 |
| 달리기 | 빠른 몸 흔들림 |
| 대시 | 진행 방향으로 늘이기 |
| 피격 | 좌우 흔들기 |
| 던지기 | 짧게 앞으로 늘이기 |
| 상호작용 (스위치 누르기, 공 차기) | 짧게 앞으로 늘이기 |
| 치즈 먹기 (레벨업) | 짧게 부풀리기 |

**고양이 애니메이션 (11)**

| 애니메이션 | 쓰는 때 | 코드 움직임 (대체) |
|---|---|---|
| Idle | 순찰 대기, 조사 대기 | 없음 |
| 걷기 | 순찰, 조사, 귀가, 재입장 | 몸 흔들림, 꼬리 회전 |
| 달리기 | 추적, 게으름냥 기상 질주, 퇴장 | 빠른 몸 흔들림 |
| 먹기 | 미끼 먹는 중 | 고개 위아래 |
| 수면 | 게으름냥 잠 | Y 0.7배로 납작하게 |
| 기상 | 게으름냥이 깰 때 | 위로 짧게 튀기 |
| 기절 | 함정에 맞음 | 좌우 흔들기 |
| 웅크림 | 사냥꾼냥 덮치기 준비 (제자리) | 납작하게 |
| 덮치기 | 잡기, 사냥꾼냥 도약 | 몸을 늘여 포물선 |
| 헛디딤 | 사냥꾼냥 덮치기 빗나감 | 좌우 흔들기 |
| 공놀이 | 사냥꾼냥이 공을 잡음 | 제자리에서 좌우 흔들기 |

- 리깅·애니메이션 담당: 리깅은 AI가 한다. 애니메이션은 AI가 무료·라이선스 확인된 클립을 추천하거나 사용자가 구해 온다 (D-054).

## 4. 근거

- 쥐 외형은 원문 그대로다. 이름은 원문 후보 "치즈"가 아이템 이름과 겹쳐 "모찌"로 정했다 (D-008).
- 고양이 4~5배: 쥐가 압도되는 느낌.
- 메시 1개 + 재질 슬롯 3개 (D-049): 가장 비싼 자원인 사용자 모델링을 줄인다. 고양이 3종은 생김새보다 무엇에 속는지로 구분하므로 색·비율·소품이면 충분하다. 줄무늬는 텍스처나 마스크가 필요해 뺐다.
- 사냥꾼냥은 검정 몸이 어두운 바닥에 묻힐 수 있어 흰 배·주둥이와 붉은 발광 눈으로 구분한다.
- 리깅·애니메이션 (D-049): 사용자가 쥐·고양이에 적용하기로 했다. 모델이 늦어도 게임 개발이 멈추지 않게 코드 움직임을 먼저 둔다.
- 아기 쥐는 엔딩 1컷만 (D-048): 매 판 배웅·맞이는 판마다 시간이 들고 반복되어 없앴다.
