# 아트 디렉션

<aside>
📌

**상태:** 초안

**관련 결정:** D-011

**한 줄 요약:** 로우폴리 + 파스텔톤 + 따뜻한 야간 조명의 미니어처 디오라마. 색·조명·폴리 기준과 모델링 순서.

</aside>

## 1. 목표

- 무섭기보다 **아기자기한 장난감 집에 몰래 들어온 쥐** 느낌.
- 직접 만든 모델과 AI 생성·무료 에셋을 섞어도 톤이 맞게 한다.

## 2. 규칙

- **형태:** 둥글고 통통한 실루엣, 단순한 면 처리. 텍스처는 단색에 가까운 컬러와 약한 그라데이션.
- **노랑(`#FFD23F`)은 함정과 치즈에만 쓴다.** 상호작용할 수 있는 것을 색으로 바로 알아보게 한다.
- **붉은 주황(`#E4572E`)은 위험에만 쓴다** (사냥꾼냥, 경고 표시).
- **조명:** 달빛(푸른색) + 창밖 가로등(주황) + 스탠드 불빛. 5단계부터 창에서 따뜻한 아침빛이 들어와 점점 밝아진다 (→ [시간 진행](../진행/시간_진행.md)).
- **모델링 순서:**
  1. 쥐 (가장 먼저 완성해서 스타일 기준 확정)
  2. 고양이 1종 (호기심냥) → 나머지는 변형으로 제작
  3. 기능 소품 5종 (컵, 청소기, 선풍기, 쥐구멍, 치즈)
  4. 구조 소품 (식탁, 소파, 러그, 벽, 바닥)
  5. 장식 소품
- 구조·장식 소품은 Kenney 무료 팩이나 Unity Asset Store 무료 로우폴리 가구로 대체해도 된다. 기능 소품과 쥐·고양이는 직접 만든다.
- AI 3D 생성 도구(Meshy, Tripo 등)를 쓰면 프롬프트에 `low poly, pastel color, rounded shapes, toy-like`를 공통으로 넣는다. 생성 후 폴리 수 줄이기와 피벗 정리를 한다.

## 3. 수치

### 컬러 팔레트

| 용도 | 색상 |
|---|---|
| 밤 분위기 베이스 | 남색 `#2B3A67`, 보라 `#5B5F97` |
| 바닥 / 가구 | 따뜻한 베이지 `#E6C9A8`, 갈색 `#A67B5B` |
| 쥐 | 회색 `#B8B8C0`, 귀/코 핑크 `#F4A6B0` |
| 치즈 / 상호작용 포인트 | 노랑 `#FFD23F` |
| 위험 | 붉은 주황 `#E4572E` |

### 폴리 가이드

| 대상 | tris |
|---|---|
| 캐릭터 (쥐·고양이) | 3,000 ~ 6,000 |
| 기능 소품 | 500 ~ 2,000 |
| 장식 소품 | 200 ~ 800 |

- 고양이는 동시에 6~8마리 나오므로 고양이 폴리 수는 늘리지 않는다.

## 4. 근거

- 전부 원문 그대로다.
- 노랑·붉은 주황 전용 규칙: 쿼터뷰에서 작게 보여도 "누를 것"과 "피할 것"을 색만으로 구분하게 한다.

## 5. 연출·피드백

| 시점 | 조명 |
|---|---|
| 1~4단계 | 달빛 + 가로등 + 스탠드 |
| 5단계 | 창으로 아침빛이 점점 들어옴 |
| 승리 | 방 전체가 아침빛 |
