# 아트 디렉션

<aside>
📌

**상태:** 초안

**관련 결정:** D-011, D-049, D-060, D-062

**한 줄 요약:** 로우폴리 + 파스텔톤 + 따뜻한 야간 조명의 미니어처 디오라마. 색·조명·폴리 기준, 소품 제작 순서, 효과음 목록.

</aside>

## 1. 목표

- 무섭기보다 **아기자기한 장난감 집에 몰래 들어온 쥐** 느낌.
- 직접 만든 모델과 AI 생성·무료 에셋을 섞어도 톤이 맞게 한다.
- 새로 만드는 모델은 최소로 한다. 고양이 메시 1개와 선풍기 1개다.

## 2. 규칙

- **형태:** 둥글고 통통한 실루엣, 단순한 면 처리. 텍스처는 단색에 가까운 컬러와 약한 그라데이션. 쥐·고양이는 텍스처 없이 단색 재질을 쓴다 (→ [캐릭터 디자인](캐릭터_디자인.md)).
- **노랑(`#FFD23F`)은 함정, 치즈, 상호작용 대상에만 쓴다.** 함정 효과 범위, 스위치와 낙하점을 잇는 선, 치즈, 장난감 공 테두리가 해당한다. 상호작용할 수 있는 것을 색으로 바로 알아보게 한다.
- **붉은 주황(`#E4572E`)은 위험에만 쓴다** (사냥꾼냥 덮치기 착지 표시, 경고 표시).
- **조명:** 달빛(푸른색) + 창밖 가로등(주황) + 스탠드 불빛. 5단계부터 창에서 따뜻한 아침빛이 들어와 점점 밝아진다 (→ [시간 진행](../진행/시간_진행.md)).
- **제작 순서:**
  1. 쥐: 기존 모델을 쓴다. 리깅과 애니메이션을 더한다.
  2. 고양이 메시 1개: 3종은 재질 슬롯과 비율로 만든다. 도형 고양이로 3종이 구분되는지 먼저 확인한 뒤 시작한다 (→ [프로젝트](../00_프로젝트.md) 로드맵).
  3. 선풍기: 받침, 기둥, 머리, 날개를 나눈다. 날개 회전은 코드로 한다. 늦어지면 원기둥 도형으로 먼저 진행한다.
  4. 구조 소품 (식탁, 소파, 러그, 벽, 바닥)
  5. 장식 소품
- **기존 모델 재사용:** 컵과 로봇청소기는 이미 있는 모델을 쓴다. 컵은 같은 모델을 낙하 위치 2곳에 두고 한 곳만 켠다.
- **도형으로 만드는 것:** 장난감 공, 쥐구멍, 펫도어, TV장, 충전독, 치즈, 고양이 소품(방울, 목도리), 착지·경고 표시, 카드 아이콘(원형 배경에 기호). 사용자 모델링은 없다.
- 구조·장식 소품은 Kenney 무료 팩이나 Unity Asset Store 무료 로우폴리 가구로 대체해도 된다. 고양이 메시와 선풍기는 직접 만든다. 쥐는 기존 모델을 쓴다.
- AI 3D 생성 도구(Meshy, Tripo 등)를 쓰면 프롬프트에 `low poly, pastel color, rounded shapes, toy-like`를 공통으로 넣는다. 생성 후 폴리 수 줄이기와 피벗 정리를 한다.
- **BGM:** 있다. VARCO로 생성한 음원을 쓴다. 시간대(5단계 고조 포함)에 맞춰 바꾼다 (→ [시간 진행](../진행/시간_진행.md)).
- **효과음:** 모두 코드로 만든 합성음이다. 효과음에는 외부 음원을 쓰지 않는다. 목록에 없는 소리는 연출 표에 쓰지 않는다. 추적 시작은 야옹, 경보는 단계 전환과 증원 입장에 쓰고, 게으름냥 기상은 따로 전용 음을 쓴다.

## 4. 근거

- 스타일·팔레트·조명·폴리는 원문 그대로다.
- 노랑·붉은 주황 전용 규칙: 방 전체가 보이는 화면에서 작게 보여도 "누를 것"과 "피할 것"을 색만으로 구분하게 한다.
- 새 모델 최소화 (D-049): 사용자 모델링이 가장 비싼 자원이다. 밤·규칙·배치는 데이터로 늘리고 모델은 고양이 메시 1개와 선풍기 1개만 새로 만든다. 나머지 기능 소품은 기존 모델이나 도형으로 충분하다.
- 게으름냥 전용 기상음: 경보와 야옹이 이미 다른 사건을 뜻해서, 가장 위험한 사건인 기상을 귀로 구분하려면 전용 음이 필요하다.
- 효과음 목록을 연출 표 기준으로 다시 모음 (D-049): 처음 18종은 다른 문서 연출 표의 소리를 다 담지 못했다. 합성음이라 개수가 늘어도 리소스 부담이 작다. 같은 뜻의 소리는 한 이름으로 합쳤다 (승리와 승리 알람 → 알람, 컵 낙하음 → 쨍그랑, 고양이 울음 → 야옹).
