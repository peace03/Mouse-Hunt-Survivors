# 선풍기

<aside>
📌

**상태:** 초안

**관련 결정:** D-011, D-012, D-017, D-024, D-030, D-040, D-044, D-045

**한 줄 요약:** 바람으로 고양이를 밀어 청소기 경로로 보내는 연결용 함정.

</aside>

## 1. 목표

- 혼자서는 약하지만 청소기와 이어 쓰면 강한 함정. "바람으로 청소기 길에 밀어 넣는" 연계를 만든다.
- 6일째 밤의 새 요소다. 그 밤은 컵이 고장 나서 이 연계를 배운다 (→ [캠페인](../진행/캠페인.md)).
- 일정이 밀리면 버릴 수 있는 기능이다 (버릴 순서 → [00_프로젝트](../00_프로젝트.md)).

## 2. 규칙

- 공통 규칙은 [함정 공통](함정_공통.md)을 따른다. 스위치는 선풍기 본체 뒤 바닥에 있다.
- 선풍기는 소파 옆에서 청소기 경로의 소파 앞 구간을 향한다. 방향은 고정이다 (→ [맵](../월드/거실_주방_맵.md)).
- 스위치는 충전독에서 12m 안에 둔다. 청소기를 켜고 선풍기로 가거나, 선풍기를 켜고 충전독으로 가는 두 순서 모두 쓸 수 있다.
- 누르기가 끝나면 작동 시간 동안 부채꼴 바람이 분다. 부채꼴은 늘 표시한다.
- 바람 안의 고양이는 바람 방향으로 밀리고, 바람 안에 있는 동안 스스로 움직이지 못한다.
- 한 번 작동하는 동안 고양이마다 처음 바람에 닿을 때 한 번 피해를 받는다. 기절은 없다.
- 기절이 없으므로 바람에 밀린 고양이는 스위치를 조사하러 오지 않는다.

## 3. 수치

| 항목 | 값 | 비고 |
|---|---|---|
| 작동 시간 | 10초 | 초기값, 플레이테스트 후 확정 |
| 바람 길이 | 6m | 센 바람 카드로 최대 10m |
| 바람 각도 | 40° | |
| 미는 속도 | 4 m/s | |
| 피해 | 1 | |
| 쿨타임 | 18초 | |
| 스위치 위치 | 본체 뒤 1m | |

모든 값은 초기값이며, 플레이테스트 후 확정한다.

## 4. 근거

- 작동 시간·쿨타임·"함정 위치로 보냄"은 원문 그대로다.
- 피해 1 (D-012): 피해가 0이면 쫓아내기 계산에 안 들어가 고를 이유가 약하다. 1이면 호기심냥(3)을 컵(2) + 선풍기(1)로 쫓아낼 수 있다. 주 역할은 밀기라서 다른 함정보다 낮다.
- 미는 속도 4 > 조사 이동 3.5: 바람을 거슬러 걸어올 수 없다.
- 스위치를 본체 뒤에 둔다: 바람은 앞으로만 불어서 스위치는 늘 범위 밖이다.
- 스위치 ~ 충전독 12m: 선풍기 10초 안에 걸어서 청소기까지 켤 수 있다.
- 수면 지점을 부채꼴 밖에: 바람이 잠든 게으름냥에 닿으면 잠든 채 피격으로 깨어 스위치로 질주한다. 쥐가 통제할 수 없는 기상을 배치에서 없앤다.

## 6. 연관 기능

- [함정 공통](함정_공통.md): 스위치, 누르기, 범위 표시
- [로봇청소기](로봇청소기.md): 밀어 보낼 목표 (청소기 경로)
- [고양이 공통](../적/고양이_공통.md): 피해·밀림
- [업그레이드](../성장/업그레이드.md): 센 바람, 진화 바람 맞은 고양이(바람에 닿은 고양이는 청소기 피해 ×2)
- [맵](../월드/거실_주방_맵.md): 소파 옆 위치, 충전독과의 거리, 수면 지점
- [디버그](../디버그/디버그.md): 레이아웃 자동 검사 2(수면 지점은 최대 부채꼴에서 떨어뜨림)
- [캠페인](../진행/캠페인.md): 6일째 새 요소, 컵 고장
