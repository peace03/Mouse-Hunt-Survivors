# 컵 밀기

<aside>
📌

**상태:** 초안

**관련 결정:** D-011, D-012, D-017, D-025

**한 줄 요약:** 식탁 가장자리의 컵을 떨어뜨려 낙하 지점의 고양이에게 피해와 긴 기절을 준다.

</aside>

## 1. 목표

- 한 방이 가장 센 함정. 타이밍 맞춰 정확한 위치에 고양이를 세워야 한다.
- 1일차 구현 대상이다.

## 2. 규칙

- 공통 규칙은 [함정 공통](함정_공통.md)을 따른다.
- 컵은 식탁 가장자리에 있고, 상호작용 지점은 그 아래 식탁 다리 옆 바닥이다.
- 작동하면 낙하 지연 뒤 컵이 정해진 낙하 지점에 떨어진다.
- 컵이 떨어지는 순간 낙하 반경 안의 고양이는 피해를 받고 기절한다.
- 쿨타임이 끝나면 컵이 원래 자리에 다시 나타난다.

## 3. 수치

| 항목 | 값 |
|---|---|
| 낙하 지연 | 0.5초 |
| 낙하 반경 | 3m |
| 피해 | 2 |
| 기절 | 4초 |
| 쿨타임 | 20초 |
| 맵의 개수 | 1 (식탁) |

모든 값은 초기값이며, 플레이테스트 후 확정한다.

## 4. 근거

- 반경·피해·기절·쿨타임은 원문 그대로다.
- 피해 2 (D-012): 세 함정 중 가장 세다. 호기심냥(3)은 컵 + 선풍기, 사냥꾼냥(4)은 컵 2번 또는 컵 + 청소기로 쫓아낸다.
- 낙하 지연 0.5초: 작동 순간이 아니라 "0.5초 뒤 고양이 위치"를 읽어야 해서 타이밍 판단이 생긴다.

## 5. 연출·피드백

| 시점 | 화면 | 소리 | 애니메이션 |
|---|---|---|---|
| 작동 | 컵이 흔들리고 낙하 지점에 그림자 커짐 | 달그락 | 쥐 상호작용 |
| 낙하 | 파편 이펙트 | 쨍그랑 | 컵 낙하 |
| 맞은 고양이 | 별 빙글 | 띵 | 기절 |
| 컵 복귀 | 반짝이며 나타남 | - | - |

## 6. 연관 기능

- [함정 공통](함정_공통.md): 작동 방식
- [고양이 공통](../적/고양이_공통.md): 피해·기절
- [업그레이드](../성장/업그레이드.md): 기절 시간, 낙하 범위, 시너지(선풍기 → 컵 피해 2배)
- [맵](../월드/거실_주방_맵.md): 식탁 위치
