# 컵 밀기

<aside>
📌

**상태:** 초안

**관련 결정:** D-011, D-012, D-017, D-025, D-040, D-045, D-047

**한 줄 요약:** 6m 떨어진 스위치를 눌러 식탁 가장자리의 컵을 떨어뜨리고, 낙하 지점의 고양이에게 피해와 긴 기절을 준다.

</aside>

## 1. 목표

- 한 방이 가장 센 함정. 고양이를 낙하 지점에 세우고, 6m 떨어진 스위치에서 눌러야 한다.
- 1일째 밤의 첫 함정이다 (→ [캠페인](../진행/캠페인.md)).

## 2. 규칙

- 공통 규칙은 [함정 공통](함정_공통.md)을 따른다.
- 컵은 1개다. 낙하 자리는 식탁(A)과 주방 조리대(B) 두 곳이 있고, 한 판에는 한 곳만 켠다. 기본은 A다 (배치 → [맵](../월드/거실_주방_맵.md), B를 쓰는 판 → [캠페인](../진행/캠페인.md)).
- 스위치는 가구 반대편 바닥에 있고, 낙하 중심에서 6m 떨어져 있다. A와 B 모두 같은 거리다.
- 스위치와 낙하 지점을 잇는 연결선을 표시한다.
- 누르기(0.5초)가 끝나면 낙하 지연 뒤 컵이 낙하 지점에 떨어진다. 누르기 시작부터 낙하까지 1.0초다.
- 컵이 떨어지는 순간 낙하 반경 안의 고양이는 피해를 받고 기절한다.
- 맞은 고양이는 기절이 끝나면 스위치를 조사하러 온다 (→ [고양이 공통](../적/고양이_공통.md)).
- 쿨타임이 끝나면 컵이 원래 자리에 다시 나타난다.
- 진화 카드 '치즈 컵'을 가지면, 범위 안에서 고양이가 미끼를 먹기 시작하고 쿨타임이 찼을 때 컵이 저절로 떨어진다. 누르는 소리는 없다 (→ [업그레이드](../성장/업그레이드.md)).

## 3. 수치

| 항목 | 값 | 비고 |
|---|---|---|
| 스위치 ~ 낙하 중심 | 6m | 초기값. 큰 컵 최대 반경과 상호작용 반경보다 길어야 함 |
| 누르기 | 0.5초 | 함정 공통 |
| 낙하 지연 | 0.5초 | 초기값 |
| 낙하 반경 | 3m | 큰 컵 카드로 최대 4m |
| 피해 | 2 | |
| 기절 | 4초 | |
| 쿨타임 | 20초 | |
| 컵 개수 | 1 | 낙하 자리 2곳 중 1곳만 켬 |

모든 값은 초기값이며, 플레이테스트 후 확정한다.

## 4. 근거

- 반경·피해·기절·쿨타임은 원문 그대로다.
- 피해 2 (D-012): 세 함정 중 가장 세다. 호기심냥(3)은 컵 + 선풍기, 사냥꾼냥(4)은 컵 2번 또는 컵 + 청소기로 쫓아낸다.
- 스위치 6m: 큰 컵 최대 반경 4m + 상호작용 반경 1.2m = 5.2m라, 6m면 범위 끝에서 0.8m 여유가 남는다. 가장 예민한 청각(사냥꾼냥 ×1.5, 추위 예민한 귀 ×1.15)으로 들어도 누르는 소리는 3 × 1.5 × 1.15 ≈ 5.2m라 낙하 중심에 닿지 않는다. 미끼 사거리 8m라 스위치에서 낙하 중심까지 던질 수 있다.
- 누르기부터 낙하까지 1.0초: 미끼가 낙하 중심에 있으면 E를 눌러 맞힐 수 있는 시간은 약 3.5초다(먹기 1.5초 포함). 먹는 모습을 보고 눌러도 맞는다. 기술은 누르는 순간보다 데려오는 동선과 빠지는 동선에 있다.
- 빠지는 여유: 컵에 맞은 호기심냥은 기절 4초 뒤 6m를 약 1.7초에 걸어온다. 쥐는 누른 뒤 약 6.7초 안에 스위치에서 2m 밖으로 빠지면 된다.
- 치즈 컵: 쥐가 스위치에 서 있을 이유를 없애고, 범위 밖에서 미끼를 던지는 자리 판단만 남긴다.
