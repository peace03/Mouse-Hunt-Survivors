# 로봇청소기

<aside>
📌

**상태:** 초안

**관련 결정:** D-011, D-012, D-017, D-025

**한 줄 요약:** 충전독에서 출발해 정해진 경로를 돌며 닿은 고양이를 밀어내고 기절시킨다.

</aside>

## 1. 목표

- 경로를 외워 그 위로 고양이를 끌고 가는 함정. 잘 쓰면 여러 마리를 한 번에 친다.

## 2. 규칙

- 공통 규칙은 [함정 공통](함정_공통.md)을 따른다. 상호작용 지점은 충전독 옆 바닥이다.
- 작동하면 작동 시간 동안 정해진 경로(맵에 놓은 경로점 순환)를 따라 움직이고, 끝나면 충전독으로 돌아간다. 경로는 충전독 → 중앙 공터 → 쥐구멍 ② 앞 → 러그 → 소파 앞 → 충전독으로 도는 고리다 (→ [맵](../월드/거실_주방_맵.md)).
- 작동 시간 동안 닿은 고양이는 피해를 받고, 진행 방향 옆으로 밀려나며 기절한다.
- 한 번 작동하는 동안 같은 고양이는 한 번만 맞는다.
- 충전독으로 돌아가는 동안에는 효과가 없다.
- 쥐는 청소기와 부딪히지 않는다.
- 쿨타임은 작동한 순간부터 돈다.

## 3. 수치

| 항목 | 값 |
|---|---|
| 작동 시간 | 8초 |
| 이동 속도 | 3 m/s |
| 피해 | 2 |
| 밀려나는 거리 | 2m |
| 기절 | 2초 |
| 쿨타임 | 25초 |

모든 값은 초기값이며, 플레이테스트 후 확정한다.

## 4. 근거

- 작동 시간·기절·쿨타임은 원문 그대로다.
- 피해 2 (D-012): 쿨타임이 가장 길고 기절이 짧은 대신 여러 마리를 칠 수 있다. 피해가 없으면 쫓아내기에 기여하지 못해 고를 이유가 약하다.
- 경로 고정: 플레이어가 경로를 외워 유인 위치를 설계할 수 있다.
- 쥐와 충돌 없음: 함정은 쥐에게 해를 주지 않는다는 공통 규칙과 맞춘다.

## 5. 연출·피드백

| 시점 | 화면 | 소리 | 애니메이션 |
|---|---|---|---|
| 대기 | 센서 노란 빛 | - | - |
| 작동 | 회전등, 경로가 바닥에 잠깐 표시 | 웅~ | 본체 이동 |
| 맞은 고양이 | 놀라 튀어오름, 별 빙글 | 쿵 + 놀란 울음 | 기절 |
| 복귀 | 회전등 꺼짐 | 삑 | - |

## 6. 연관 기능

- [함정 공통](함정_공통.md): 작동 방식
- [고양이 공통](../적/고양이_공통.md): 피해·기절·밀림
- [업그레이드](../성장/업그레이드.md): 쿨타임, 작동 시간, 시너지(청소기 경로 치즈 흔적)
- [맵](../월드/거실_주방_맵.md): 충전독 위치와 경로
- [선풍기](선풍기.md): 고양이를 소파 앞 경로로 밀어 보낸다
