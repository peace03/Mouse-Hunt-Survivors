# 함정 공통

<aside>
📌

**상태:** 초안

**관련 결정:** D-011, D-017

**한 줄 요약:** 모든 함정이 공유하는 작동 방식(상호작용 지점, 쿨타임, 범위 표시).

</aside>

## 1. 목표

- 함정이 쥐의 유일한 공격 수단이다. "유인 → 위치 선점 → 작동"이 핵심 플레이다.
- 플레이어가 "지금 고양이가 범위 안인가"를 눈으로 판단할 수 있어야 한다.

## 2. 규칙

- 함정마다 바닥에 상호작용 지점이 있다. 쥐가 지점의 상호작용 반경 안에서 상호작용 키를 누르면 작동한다.
- 작동하면 쿨타임이 돈다. 쿨타임 중에는 작동하지 않는다.
- 작동할 수 있는 함정은 노란색(`#FFD23F`)으로 빛나고, 쿨타임 중에는 회색이다.
- 쥐가 상호작용 지점 근처에 오면 그 함정의 효과 범위가 바닥에 표시된다.
- 함정은 쥐에게 영향을 주지 않는다.
- 함정 작동은 소음을 내지 않는다.
- 함정마다 피해·기절·밀어내기 효과가 다르다 (각 함정 문서).

## 3. 수치

| 항목 | 값 |
|---|---|
| 상호작용 반경 | 1.2m |
| 효과 범위 표시 거리 (쥐 ↔ 상호작용 지점) | 4m |

모든 값은 초기값이며, 플레이테스트 후 확정한다.

## 4. 근거

- 원문의 "근처에서 상호작용 버튼, 함정마다 쿨타임"을 유지했다.
- 상호작용 지점을 바닥에 둔다: 컵처럼 식탁 위에 있는 함정도 쥐가 바닥에서 작동할 수 있다. 오르기 동작을 만들지 않아도 된다.
- 범위 표시: 유인 플레이의 판단 근거다. 표시가 없으면 "들어갔는지"를 감으로 맞혀야 한다.
- 노란색은 함정과 치즈에만 쓴다 (→ [아트 디렉션](../아트/아트_디렉션.md)).
- 작동 소음 없음: 함정을 쓸 때마다 다른 고양이가 몰려오면 연쇄를 예측하기 어렵다. 필요하면 나중에 넣는다.

## 5. 연출·피드백

| 시점 | 화면 | 소리 | 애니메이션 |
|---|---|---|---|
| 작동 가능 | 노란 빛, 상호작용 지점 표시 | - | - |
| 쥐가 근처 | 효과 범위 바닥 표시, 키 안내(E) | - | - |
| 작동 | 함정별 | 함정별 | 쥐 상호작용 |
| 쿨타임 중 | 회색, 남은 시간 원형 게이지 | - | - |

- [기본조작](../플레이어/기본조작.md): 상호작용 키
