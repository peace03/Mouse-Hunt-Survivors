# 기본조작

<aside>
📌

**상태:** 초안

**관련 결정:** D-011, D-017, D-019, D-035, D-037, D-038, D-043, D-050, D-061

**한 줄 요약:** 쥐의 이동 4상태(살금살금·걷기·달리기·대시 잔상)와 상태별 소리, 쥐 몸 소리 반경 계산, 입력 키(PC·모바일).

## 1. 목표

- 플레이어는 이동 속도와 소리 크기를 맞바꾸며 고양이를 피하거나 일부러 부른다.
- 달리기는 거리를 지키는 시끄러운 도망이다. 추적을 끊는 것은 열쇠(미끼·대시 잔상·공·헛디딤)다.
- 데모에서 보여줄 것: 살금살금으로 잠든 게으름냥 옆을 지나가는 장면, 대시 잔상으로 호기심냥의 추적을 끊는 장면.

## 2. 규칙

### 판 시작 대기

- PC에서는 밤 선택·인트로·재시작 뒤 ‘아무 키나 누르면 밤이 시작됩니다’를 표시한다(D-065).
- 키를 모두 놓은 뒤 새 키를 누를 때까지 게임 시계·실제 생존 시간·플레이어·고양이·함정이 멈춘다. 마우스 클릭으로는 시작하지 않는다.
- 시작 키는 해당 프레임에 대시·상호작용·일시정지·디버그 조작으로 중복 처리하지 않는다. 이동 키를 계속 누르면 다음 프레임부터 이동한다.

### 이동과 소리

- 이동 상태는 살금살금 / 걷기 / 달리기 / 대시 4가지다.
- 보조 입력 없이 움직이면 걷기다.
- 살금살금·걷기는 일반 소리, 달리기는 큰 소리를 낸다. 소리 종류별 고양이 반응은 [고양이 공통](../적/고양이_공통.md)과 [고양이 종류](../적/고양이_종류.md)에 있다.
- 멈춰 있으면 소리가 없다.
- 잠든 게으름냥은 걷기·달리기 소음 원 안에서 시간을 누적하고 수면 게이지가 없어지면 모찌를 추적한다(D-066). 살금살금은 누적하지 않지만 몸이 닿으면 즉시 깨운다.
- 쥐 몸 소리의 최종 반경은 쥐 발밑에 원으로 늘 표시한다.
- 달리기로는 방 안에서 추적을 거의 끊지 못한다. 추적 중 쥐 자리에서 난 소리는 놓침 타이머를 0으로 되돌린다(→ [고양이 공통](../적/고양이_공통.md)).
- 사냥꾼냥에게서 곧장 또는 옆으로 달아나면 덮치기는 나오지 않지만 추적도 끊기지 않는다. 멈추거나 꺾을 때 덮치기가 나온다(→ [고양이 종류](../적/고양이_종류.md)).

### 대시 잔상

- 대시는 입력 방향(입력이 없으면 바라보는 방향)으로 짧고 빠르게 이동한다.
- 대시 시작 지점에 잔상 소리를 남긴다.
- 대시 중과 대시 직후 일정 시간은 이동 소리가 없다. 깨어 있던 호기심냥·게으름냥은 잔상 지점으로 간다. 잠든 게으름냥은 대시 소음 원 안에서 즉시 깨어 모찌를 추적한다(D-066).
- 대시는 쿨타임 동안 쓸 수 없다. 대시 중 무적은 없다.

### 쥐 몸 소리 반경 계산

- 쥐 몸 소리는 살금살금·걷기·달리기·잔상 4종이다.
- 최종 반경 = 기본 반경 × 발소리 배율 × 전역 소음 배율.
- 발소리 배율 = max(하한, 1 − 단계당 감소 × 솜털 발바닥 단계). 하한은 이 배율에만 건다.
- 발소리 배율은 살금살금·걷기·달리기에만 곱한다. 잔상에는 곱하지 않는다.
- 전역 소음 배율은 쥐 몸 소리 4종에만 마지막에 곱한다. 미끼·공·스위치 소리에는 곱하지 않는다.
- 고양이 청각 배율은 이 계산 뒤에 고양이 쪽에서 곱한다(→ [고양이 공통](../적/고양이_공통.md)). 단, 잠든 게으름냥의 발소리 누적·대시 기상은 화면 원과 일치하도록 청각 배율을 더하지 않는다.
- 큰 소리인지 여부는 반경이 아니라 소리 종류로 정해진다. 솜털 발바닥은 반경만 줄이고 달리기를 일반 소리로 바꾸지 않는다.

### 상호작용

- E(상호작용)는 상호작용 반경 안의 함정 스위치와 장난감 공 중 가까운 쪽에 쓰인다. 반경과 스위치 누르기 규칙은 [함정 공통](../함정/함정_공통.md)에 있다.
- 공은 도착 위치를 정해 찬다. PC는 커서 지점, 모바일은 상호작용 버튼을 누른 채 드래그해서 정하고 떼면 찬다. 공놀이 중인 공은 찰 수 없다. 공의 움직임과 소리는 [장난감 공](../월드/장난감_공.md)에 있다.

### 모바일

- 모바일은 조이스틱 기울기로 살금살금 / 걷기 / 달리기가 나뉜다.
- 모바일 던지기: 던지기 버튼을 누른 채 끌면 끈 방향과 거리(버튼에서 멀수록 멀리, 최대 사거리까지)에 착지 표시가 나오고, 떼면 던진다. 끌지 않고 떼면 바라보는 방향 최대 사거리로 던진다.
- 모바일 카메라는 쥐 중심 확대·따라가기이고, 두 손가락 입력으로 전체 보기와 전환한다. 카메라 동작은 [거실·주방 맵](../월드/거실_주방_맵.md), 모바일 범위와 일정은 [프로젝트](../00_프로젝트.md)에 있다.

## 3. 수치

| 상태 | 이동속도 (m/s) | 기본 소리 반경 (m) | 소리 종류 |
|---|---|---|---|
| 살금살금 | 2.0 | 2 | 일반 |
| 걷기 | 4.0 | 5 | 일반 |
| 달리기 | 5.5 | 9 | 큰 소리 |
| 대시 | 거리 3m를 0.15초에 이동 | 9 (시작 지점) | 잔상 |

| 항목 | 값 | 비고 |
|---|---|---|
| 대시 쿨타임 | 4초 | 날쌘 몸으로 단계당 −1초 |
| 대시 뒤 이동 소리 없는 시간 | 0.5초 | 대시 중 포함. 그림자 대시 진화로 1.5초 |
| 발소리 배율 단계당 감소 | 0.05 | 솜털 발바닥 2단계면 0.90 |
| 발소리 배율 하한 | 0.6 | |
| 전역 소음 배율 | 1.0 | M0 측정으로 조정(검토 범위 0.55~0.70) |
| 모바일 조이스틱 구간 | 0~40% 살금살금, 40~90% 걷기, 90% 이상 달리기 | |

모든 값은 초기값이며, 인스펙터에서 조절하고 플레이테스트 후 확정한다.

### 키

| 동작 | PC | 모바일 |
|---|---|---|
| 이동 | WASD | 왼쪽 조이스틱 |
| 살금살금 | Left Ctrl 누르는 동안 | 조이스틱 약하게 |
| 달리기 | Left Shift 누르는 동안 | 조이스틱 끝까지 |
| 대시 | Space | 대시 버튼 |
| 상호작용 (함정 스위치·장난감 공) | E (공은 커서 지점으로 참) | 상호작용 버튼 |
| 치즈 던지기 | 마우스 왼쪽 클릭 (커서 지점으로) | 던지기 버튼을 누른 채 끌어 조준, 떼면 던짐 |
| 전체 보기 전환 | - (PC는 늘 방 전체) | 두 손가락 |

- Ctrl과 Shift를 함께 누르면 살금살금이 우선한다.

## 4. 근거

- 살금살금·걷기 속도와 소리는 원문 그대로다.
- 달리기 5.5: 호기심냥(추적 4.5)·사냥꾼냥(추적 5.0)보다 빨라 거리는 지키지만, 추적 중 들린 쥐 소리가 놓침 타이머를 되돌려 방 안에서는 떼지 못한다. 그래서 추적은 열쇠로 끊는다. 보름달 사냥꾼냥(5.5)과 같아지는 것은 의도다.
- 대시를 잔상으로 바꾼 이유: 이동 소리가 바로 새 위치에서 다시 나면 고양이 목표가 쥐로 돌아가 대시만 할 수 있는 일이 없다. 잔상은 '속인다'는 컨셉을 버튼 하나로 만든다.
- 솜털 발바닥을 잔상에 곱하지 않는 이유: 은신·잔상 빌드 안에서 두 카드가 서로 깎아 먹지 않게 한다.
- 전역 소음 배율을 쥐 몸 소리에만 곱하는 이유: 맵 크기에 맞춰 배율을 내려도 미끼·공·스위치가 같이 약해지지 않게 한다. 하한을 발소리 배율에만 걸어 전역 배율이 0.6보다 낮아도 솜털 발바닥은 늘 효과가 있다.
- 키보드에는 기울기가 없어 보조 키로 상태를 나눈다. Shift 달리기, Ctrl 숙이기는 PC 게임에서 익숙한 배치다.
- 살금살금 우선: 실수로 둘 다 눌렀을 때 소리가 작은 쪽이 덜 억울하다.

## 5. 연출·피드백

| 시점 | 화면 | 소리 | 애니메이션 |
|---|---|---|---|
| 살금살금 | 소리 원 작고 옅음 | 발소리 거의 없음 | 몸 낮추고 귀 눕힘 |
| 걷기 | 소리 원 중간 | 작은 발소리 | 걷기 |
| 달리기 | 소리 원 크고 진함 | 빠른 발소리 | 귀 펄럭, 꼬리 올라감 |
| 대시 | 시작 지점에 잔상과 잔상 소리 원, 쥐 발밑 원은 사라짐 | 휙 | 대시 |
| 대시 쿨타임 중 | HUD 쿨타임 표시 | - | - |

- 모델·애니메이션이 준비되기 전에는 코드 움직임(살금살금은 납작하게, 대시는 늘이기)으로 대신한다. 애니메이션 목록은 [캐릭터 디자인](../아트/캐릭터_디자인.md)에 있다.
