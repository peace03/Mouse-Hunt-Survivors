# 기본조작

<aside>
📌

**상태:** 초안

**관련 결정:** D-011, D-017, D-019

**한 줄 요약:** 쥐의 이동 4상태(살금살금·걷기·달리기·대시)와 상태별 소음, 입력 키.

</aside>

## 1. 목표

- 플레이어는 이동 속도와 소음 크기를 맞바꾸며 고양이를 피하거나 일부러 부른다.
- 데모에서 보여줄 것: 살금살금으로 잠든 고양이 옆을 지나가고, 달리기로 고양이를 함정 쪽으로 끌어오는 장면.

## 2. 규칙

- 이동 상태는 살금살금 / 걷기 / 달리기 / 대시 4가지다.
- 보조 입력 없이 움직이면 걷기다.
- 움직이는 동안 현재 상태의 소음 반경 안에 있는 고양이에게 소음이 전달된다 (→ [고양이 공통](../적/고양이_공통.md)).
- 멈춰 있으면 소음이 없다.
- 소음 반경은 쥐 발밑에 원으로 항상 표시한다.
- 대시는 입력 방향(입력이 없으면 바라보는 방향)으로 짧게 빠르게 이동하고, 시작 지점에서 소음을 낸다.
- 대시는 쿨타임 동안 쓸 수 없다. 대시 중 무적은 없다.
- 모바일은 조이스틱 기울기로 살금살금 / 걷기 / 달리기가 나뉜다.

## 3. 수치

| 상태 | 이동속도 (m/s) | 소음 반경 (m) |
|---|---|---|
| 살금살금 | 2.0 | 2 |
| 걷기 | 4.0 | 5 |
| 달리기 | 6.5 | 9 |
| 대시 | 거리 3m를 0.15초에 이동 | 9 |

| 항목 | 값 |
|---|---|
| 대시 쿨타임 | 4초 |
| 모바일 조이스틱 구간 | 0~40% 살금살금, 40~90% 걷기, 90% 이상 달리기 |

모든 값은 초기값이며, 플레이테스트 후 확정한다.

### 키

| 동작 | PC | 모바일 |
|---|---|---|
| 이동 | WASD | 왼쪽 조이스틱 |
| 살금살금 | Left Ctrl 누르는 동안 | 조이스틱 약하게 |
| 달리기 | Left Shift 누르는 동안 | 조이스틱 끝까지 |
| 대시 | Space | 대시 버튼 |
| 상호작용 (함정) | E | 상호작용 버튼 |
| 치즈 던지기 | 마우스 왼쪽 클릭 (커서 지점으로) | 던지기 버튼 |

- Ctrl과 Shift를 함께 누르면 살금살금이 우선한다.

## 4. 근거

- 상태별 속도·소음은 원문 그대로다.
- 달리기 6.5는 고양이 최고 속도 5.5보다 빠르다. 달리면 도망칠 수 있지만 소음 9m로 더 많은 고양이를 부른다. 이 맞바꿈이 이동의 핵심 선택이다.
- 키보드에는 기울기가 없어 보조 키로 상태를 나눈다. Shift 달리기, Ctrl 숙이기는 PC 게임에서 익숙한 배치다.
- 살금살금 우선: 실수로 둘 다 눌렀을 때 소음이 작은 쪽이 덜 억울하다.

## 5. 연출·피드백

| 시점 | 화면 | 소리 | 애니메이션 |
|---|---|---|---|
| 살금살금 | 소음 원 작고 옅음 | 발소리 거의 없음 | 몸 낮추고 귀 눕힘 |
| 걷기 | 소음 원 중간 | 작은 발소리 | 걷기 |
| 달리기 | 소음 원 크고 진함 | 빠른 발소리 | 귀 펄럭, 꼬리 올라감 |
| 대시 | 잔상 | 휙 | 대시 |
| 대시 쿨타임 중 | HUD 쿨타임 표시 | - | - |

## 6. 연관 기능

- [고양이 공통](../적/고양이_공통.md): 소음 위치와 반경을 넘긴다
- [체력](체력.md): 잡히면 튕겨나는 동안 조작 불가
- [치즈 던지기](치즈_던지기.md): 던지기 키
- [함정 공통](../함정/함정_공통.md): 상호작용 키
- [업그레이드](../성장/업그레이드.md): 살금살금 속도, 소음 반경, 대시 쿨타임을 바꾼다
- [HUD](../UI/HUD.md): 대시 쿨타임 표시

## 7. 확인 필요

- 모바일 치즈 던지기 조준 방식 (현재 안: 버튼을 누르면 바라보는 방향 최대 사거리로). 모바일 범위가 정해지면 결정 ([00_프로젝트](../00_프로젝트.md)).
