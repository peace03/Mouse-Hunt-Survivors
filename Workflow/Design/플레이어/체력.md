# 체력

<aside>
📌

**상태:** 초안

**관련 결정:** D-011, D-017, D-045

**한 줄 요약:** 하트 3개. 고양이에게 잡히면 1개를 잃고, 튕겨나며 잠깐 무적이 된다.

</aside>

## 1. 목표

- 실수 몇 번은 버티게 해서 유인 플레이를 시도할 여유를 준다.
- 데모에서 보여줄 것: 잡혀서 튕겨나고, 무적 동안 빠져나가는 장면.

## 2. 규칙

- 시작 하트는 3개다.
- 고양이에게 잡히면 (→ [고양이 공통](../적/고양이_공통.md)) 하트가 1개 줄어든다.
- 잡히면 쥐는 고양이 반대 방향으로 튕겨나가고, 튕겨나는 동안 조작할 수 없다.
- 잡힌 뒤 무적 시간 동안은 다시 잡히지 않는다.
- 하트가 0이 되면 패배한다 (→ [시간 진행](../진행/시간_진행.md)).
- 최대 하트는 카드 '든든한 배'로만 늘어난다. 단계마다 최대 하트 +1, 하트 1개 회복이다(→ [업그레이드](../성장/업그레이드.md)).
- 판 안에서 하트를 회복하는 방법은 든든한 배뿐이다. 레벨업 후보가 0장일 때도 회복은 없다(→ [경험치·레벨업](../성장/경험치_레벨업.md)).
- 추위 3(얇은 이불)은 시작·최대 하트를 1 줄인다. 든든한 배는 그대로 단계마다 +1이다(→ [캠페인](../진행/캠페인.md)).

## 3. 수치

| 항목 | 값 | 비고 |
|---|---|---|
| 시작 하트 | 3 | 추위 3에서 2 |
| 최대 하트 | 5 | 시작 3 + 든든한 배 2단계. 추위 3에서 4 (→ [캠페인](../진행/캠페인.md)) |
| 무적 시간 | 1.5초 | |
| 튕겨나는 거리 | 3m | |
| 튕겨나는 동안 조작 불가 | 0.3초 | |

모든 값은 초기값이며, 인스펙터에서 조절하고 플레이테스트 후 확정한다.

## 4. 근거

- 하트 3개와 무적 1.5초는 원문 그대로다.
- 최대 5: 하트 +1을 2번까지만 둔다. 그 이상이면 후반 긴장이 사라진다.
- 회복을 든든한 배 하나로 묶은 이유: 후보 0장일 때 하트 회복으로 대신하면 끝없는 밤에서 무한 회복이 생긴다.
- 튕겨나기: 고양이와 겹친 채로 무적이 끝나 연속으로 잡히는 일을 막는다.

## 5. 연출·피드백

| 시점 | 화면 | 소리 | 애니메이션 |
|---|---|---|---|
| 잡힘 | 화면 약하게 흔들림, 하트 아이콘 깨짐 | 찍 + 고양이 울음 | 피격 (놀란 눈, 털 곤두섬) |
| 무적 중 | 쥐 깜빡임 | - | - |
| 하트 회복 (든든한 배) | 하트 아이콘 채워짐 | - | - |
| 하트 0 | 패배 결과 화면 (→ [HUD](../UI/HUD.md)) | 패배음 | 피격 |

- 모델·애니메이션이 준비되기 전에는 피격을 코드 움직임으로 대신한다(→ [캐릭터 디자인](../아트/캐릭터_디자인.md)).

## 6. 연관 기능

- [고양이 공통](../적/고양이_공통.md): 잡힘 판정
- [업그레이드](../성장/업그레이드.md): 든든한 배(최대 하트 +1, 하트 1개 회복)
- [경험치·레벨업](../성장/경험치_레벨업.md): 후보 0장이면 레벨업 없음
- [캠페인](../진행/캠페인.md): 추위 3 하트 −1
- [HUD](../UI/HUD.md): 하트 표시
- [시간 진행](../진행/시간_진행.md): 하트 0이면 패배
