# 치즈 던지기

<aside>
📌

**상태:** 초안

**관련 결정:** D-011, D-017, D-037, D-039

**한 줄 요약:** 치즈를 던져 떨어진 곳에 미끼 소리를 내고, 먼저 온 고양이 한 마리를 잠시 붙잡아 두는 미끼.

</aside>

## 1. 목표

- 쥐가 직접 소리를 내지 않고 고양이를 원하는 곳(함정 범위)으로 부른다.
- 미끼는 호기심냥의 열쇠다. 같은 고양이를 미끼만으로 연달아 맞히지 못하게 해서 다른 도구와 섞어 쓰게 한다.
- 데모에서 보여줄 것: 스위치에서 컵 낙하 중심으로 치즈를 던져 호기심냥을 세우고 컵을 떨어뜨리는 장면.

## 2. 규칙

- 던지기 입력을 하면 목표 지점(최대 사거리 이내)으로 치즈가 포물선을 그리며 날아간다.
- 던질 때 쥐 자리에서는 고양이가 듣는 소리가 나지 않는다(효과음만).
- 치즈가 떨어진 지점에서 미끼 소리가 한 번 난다. 미끼 소리에는 전역 소음 배율과 솜털 발바닥을 곱하지 않는다. 고양이 청각 배율은 곱한다(→ [고양이 공통](../적/고양이_공통.md)).
- 미끼 반응은 종류마다 다르다. 미끼로 추적을 끊는 것은 호기심냥뿐이다(→ [고양이 종류](../적/고양이_종류.md)).
- 치즈에 처음 도착한 고양이 한 마리만 먹는다. 먹는 동안 멈춘다. 다 먹으면 치즈가 사라진다.
- 다른 고양이가 먹기 시작하면 그 미끼를 향하던 다른 고양이의 목표는 끝난다(→ [고양이 공통](../적/고양이_공통.md)).
- 미끼로 가는 중이거나 먹는 중인 고양이도 쥐가 잡힘 거리 안에 들어오면 잡는다.
- 미끼를 먹기 시작한 고양이는 미끼 내성 시간 동안 미끼에 반응하지 않는다. 내성은 고양이마다 따로 걸린다.
- 1일째는 미끼 내성이 없다(→ [캠페인](../진행/캠페인.md)).
- 미끼 내성은 컵 쿨타임보다 짧게 내리지 않는다.
- 아무 고양이도 먹지 않으면 일정 시간 뒤 사라진다.
- 던지기는 쿨타임만 있고 개수 제한은 없다.
- 미끼 치즈는 쥐가 주울 수 없고 경험치가 아니다.

## 3. 수치

| 항목 | 값 | 비고 |
|---|---|---|
| 최대 사거리 | 8m | |
| 쿨타임 | 5초 | 실제 시간 |
| 비행 시간 | 0.5초 | |
| 미끼 소리 반경 | 6m | |
| 먹는 시간 | 1.5초 | 쫀득한 치즈로 단계당 +0.5초 |
| 먹기 시작 거리 | 0.6m | |
| 잡힘 거리 | 0.8m | 미끼로 가는 중·먹는 중에도 같음 |
| 미끼 내성 | 30초 | 실제 시간. 1일째 0. 컵 쿨 20초보다 짧게 내리지 않음 |
| 아무도 안 먹을 때 사라지는 시간 | 10초 | |
| 동시에 놓일 수 있는 미끼 | 3개 | |

모든 값은 초기값이며, 인스펙터에서 조절하고 플레이테스트 후 확정한다.

## 4. 근거

- 미끼 소리 6m는 원문 그대로다.
- 쿨타임 5초, 개수 무제한: 개수를 세는 자원 관리 대신 "언제 어디에 던지나" 판단에 집중시킨다.
- 사거리 8m: 컵 스위치(낙하 중심에서 6m)에서 낙하 중심까지 던질 수 있다.
- 먹기 3초 → 1.5초: 미끼로 고양이를 오래 묶어 두는 시간을 줄인다. 미끼가 낙하 중심에 있으면 스위치를 누를 수 있는 시간은 약 3.5초라 ♥(먹는 중)를 보고 눌러도 맞는다. 기술은 누르는 순간이 아니라 고양이를 데려오는 동선과 누른 뒤 빠지는 동선에 있다.
- 미끼 내성 30초: 미끼만으로 같은 고양이를 연달아 맞히는 것을 막는다. 컵 쿨 20초보다 길어야 '미끼와 E만으로 같은 고양이를 30초 안에 2번 맞히지 못함'이 성립한다.
- 1일째 내성 없음: 함정이 컵뿐인 1일째에 첫 '+N초' 보상을 빨리 준다.
- 미끼 중 잡힘: 미끼가 5초마다 쓰는 무적 버튼이 되지 않게 한다.
- 미끼 소리를 전역 배율 밖에 두는 이유: 맵 크기에 맞춰 쥐 몸 소리를 줄여도 도구가 같이 약해지지 않게 한다.
- 미끼는 '미끼' 종류의 소리라 잠든 게으름냥을 깨우지 않는다.
