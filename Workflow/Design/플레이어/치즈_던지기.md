# 치즈 던지기

<aside>
📌

**상태:** 초안

**관련 결정:** D-011, D-017

**한 줄 요약:** 치즈를 던져 떨어진 곳에 소음을 내고, 온 고양이를 잠시 붙잡아 두는 미끼.

</aside>

## 1. 목표

- 쥐가 직접 소리를 내지 않고 고양이를 원하는 곳(함정 범위)으로 부른다.
- 데모에서 보여줄 것: 컵 낙하 지점에 치즈를 던져 고양이를 세우고 컵을 떨어뜨리는 장면.

## 2. 규칙

- 던지기 입력을 하면 목표 지점(최대 사거리 이내)으로 치즈가 포물선을 그리며 날아간다.
- 치즈가 떨어진 지점에서 소음이 한 번 난다. 소음 반경 안의 고양이가 그곳으로 온다 (→ [고양이 공통](../적/고양이_공통.md)).
- 치즈에 처음 닿은 고양이 한 마리가 일정 시간 먹느라 멈춘다. 다 먹으면 치즈가 사라진다.
- 늦게 온 고양이는 일반 소음을 들은 것처럼 그 자리를 조사한다.
- 아무 고양이도 먹지 않으면 일정 시간 뒤 사라진다.
- 던지기는 쿨타임만 있고 개수 제한은 없다.
- 미끼 치즈는 쥐가 주울 수 없고 경험치가 아니다.

## 3. 수치

| 항목 | 값 |
|---|---|
| 최대 사거리 | 8m |
| 쿨타임 | 5초 |
| 비행 시간 | 0.5초 |
| 소음 반경 | 6m |
| 먹는 시간 | 3초 |
| 아무도 안 먹을 때 사라지는 시간 | 10초 |

모든 값은 초기값이며, 플레이테스트 후 확정한다.

## 4. 근거

- 소음 6m와 먹는 시간 3초는 원문 그대로다.
- 쿨타임 5초, 개수 무제한: 개수를 세는 자원 관리 대신 "언제 어디에 던지나" 타이밍 판단에 집중시킨다. 함정 쿨타임(18~25초)보다 짧아 함정을 한 번 쓸 동안 미끼를 3~4번 쓸 수 있다. 유인의 주력 도구다.
- 소음 6m는 게으름냥 기상 기준(9m 이상)보다 작아서 잠든 고양이를 깨우지 않는다 (→ [고양이 종류](../적/고양이_종류.md)).

## 5. 연출·피드백

| 시점 | 화면 | 소리 | 애니메이션 |
|---|---|---|---|
| 조준 (PC) | 커서 지점에 착지 표시, 사거리 밖이면 사거리 끝에 표시 | - | - |
| 던짐 | 노란 치즈 포물선 | 휙 | 던지기 |
| 착지 | 노란 원이 소음 반경까지 퍼짐 | 톡 | - |
| 고양이가 먹음 | 냠냠 이펙트, 남은 시간 원형 게이지 | 냠냠 | 고양이 Idle (먹기) |

## 6. 연관 기능

- [기본조작](기본조작.md): 던지기 키
- [고양이 공통](../적/고양이_공통.md): 소음 위치와 반경, 먹는 동안 멈춤
- [업그레이드](../성장/업그레이드.md): 사거리, 먹는 시간
- [HUD](../UI/HUD.md): 쿨타임 표시
