# 스토리

<aside>
📌

**상태:** 초안

**관련 결정:** D-020, D-021, D-022

**한 줄 요약:** 집사가 잠든 밤, 모찌가 가족을 위해 치즈를 모으며 6시 알람까지 버티는 이야기. 텍스트 카드와 짧은 연출로만 전달한다.

</aside>

## 1. 목표

- 게임 규칙(펫도어 재입장, 6시 승리, 치즈 모으기)에 이야기상 이유를 붙여 플레이어가 규칙을 설명 없이 받아들이게 한다.
- 컷신·음성·일러스트 없이 텍스트와 게임 안 연출만 쓴다.
- 데모에서 보여줄 것: 가족의 배웅을 받고 나서는 모찌, 알람이 울리자 밥그릇으로 달려가는 고양이들, 가족에게 돌아오는 모찌.

## 2. 규칙

**설정**
- 집사가 잠든 밤에는 고양이 세 마리가 거실과 주방을 차지한다. 집사는 화면에 나오지 않는다.
- 모찌는 쥐구멍 ②(벽 속)에 가족과 함께 산다. 겨울을 날 치즈를 모으려고 밤마다 나온다.
- 함정은 고양이를 놀라게 할 뿐 다치게 하지 않는다. 놀란 고양이는 펫도어로 뛰쳐나가며 물고 있던 큰 치즈를 떨어뜨리고, 진정되면 펫도어로 돌아온다 (→ [고양이 공통](../적/고양이_공통.md)).
- 6시에 집사의 알람이 울리면 고양이들은 아침밥을 먹으러 밥그릇으로 달려간다. 이것이 승리다.
- 하트를 모두 잃으면 모찌는 겁에 질려 쥐구멍으로 도망친다. 다치는 표현은 없다.

**한 판 순서**
1. 인트로 카드 3장 (아래 문구). 아무 키·클릭으로 다음 카드, Esc로 전부 건너뛴다.
2. 배웅 연출: 쥐구멍 ② 앞에서 가족이 모찌를 배웅하고 모찌가 나선다. 아무 키로 건너뛸 수 있다.
3. 플레이 (5분). 게임 시계는 배웅 연출이 끝난 순간부터 흐른다 (→ [시간 진행](시간_진행.md)).
4. 6:00이 되면 승리 연출, 하트가 0이 되면 패배 연출.
5. 결과 화면 (→ [HUD](../UI/HUD.md)).

- "다시 하기"로 시작하면 인트로 카드는 생략하고 배웅 연출부터 한다.

**승리 연출**
1. 알람 소리와 함께 화면 위에 승리 문구가 뜬다. 모든 고양이가 행동을 멈추고 밥그릇으로 달려간다. 조작은 막힌다.
2. 화면이 어두워졌다 밝아지면 쥐구멍 ② 앞이다. 모찌가 큰 치즈를 들고 들어가고 가족이 맞이한다.
3. 결과 화면.

**패배 연출**
1. 모찌가 피격 모션을 한 뒤 화면이 어두워진다.
2. 결과 화면.

### 문구

| 쓰는 곳 | 문구 |
|---|---|
| 인트로 카드 1 | 집사가 잠들면, 이 집은 고양이들 차지가 된다. |
| 인트로 카드 2 | 벽 속에 사는 쥐 모찌는 가족과 겨울을 날 치즈가 필요하다. |
| 인트로 카드 3 | 아침 6시, 알람이 울릴 때까지 버텨라! |
| 1단계 시작 | 집사가 잠들었다. 고양이들의 시간이다. |
| 2단계 시작 | 호기심냥이 한 마리 더 내려왔다. |
| 3단계 시작 | 사냥꾼냥이 깼다. 대시를 조심해! |
| 4단계 시작 | 고양이가 점점 많아진다… |
| 5단계 시작 | 창밖이 밝아온다. 게으름냥도 일어났다! |
| 승리 | 따르릉! 아침이다! |
| 패배 | 모찌는 쥐구멍으로 도망쳤다… |

- 단계 문구가 뜨는 시점은 [시간 진행](시간_진행.md)의 단계 전환이다.

## 3. 수치

| 항목 | 값 |
|---|---|
| 배웅 연출 길이 | 3초 |
| 승리: 고양이가 밥그릇으로 달려가는 시간 | 2초 |
| 승리: 맞이 연출 길이 | 3초 |
| 패배: 화면이 어두워지기까지 | 1.5초 |
| 화면 어두워짐 / 밝아짐 | 각 0.5초 |
| 단계 문구 표시 시간 | 3초 |

모든 값은 초기값이며, 플레이테스트 후 확정한다.

## 4. 근거

- 집사·펫도어·알람 (D-020): 설정 하나로 규칙 세 개(출입구·재입장·6시 승리)가 설명된다. 집사를 화면에 내지 않아 사람 모델이 필요 없다.
- 가족 (D-021): "치즈를 왜 모으나"를 문구가 아니라 처음과 끝 장면으로 보여준다. 승리가 "살아남았다"에서 "가족에게 돌아왔다"가 된다.
- 텍스트만 쓴다 (D-022): 마감 안에 아트 작업을 늘리지 않는다. 카드 UI 하나와 문구 데이터로 끝난다.
- 패배를 "도망쳤다"로: 원문의 "고양이는 쓰러지지 않고 쫓겨난다"와 같은 귀여운 톤을 쥐 쪽에도 맞춘다.
- 시계를 배웅 뒤부터: 연출을 보는 동안 5분이 줄면 억울하다.

## 5. 연출·피드백

| 시점 | 화면 | 소리 | 애니메이션 |
|---|---|---|---|
| 인트로 카드 | 남색(`#2B3A67`) 바탕에 문구, 카드 넘김 | 카드 넘김 | - |
| 배웅 | 쥐구멍 ② 앞, 가족이 쥐구멍 안에서 손 흔듦 | 작은 찍찍 | 모찌 Idle → 걷기 |
| 승리 | 방 전체 아침빛 (→ [아트 디렉션](../아트/아트_디렉션.md)), 고양이들 밥그릇으로 질주 | 알람 따르릉 → 새소리 | 고양이 달리기 |
| 맞이 | 쥐구멍 ② 앞, 가족이 모찌를 맞음 | 찍찍 | 모찌 치즈 먹기 (볼 빵빵) |
| 패배 | 화면 어두워짐 | 패배음 | 모찌 피격 |
