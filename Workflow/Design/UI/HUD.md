# HUD

<aside>
📌

**상태:** 초안

**관련 결정:** D-017, D-022, D-023, D-027, D-035, D-041, D-044, D-048, D-050, D-066, D-067, D-068

**한 줄 요약:** 게임의 모든 화면. 타이틀, 밤 선택, 플레이 중 HUD, 텍스트 패널(인트로·엔딩), 새 요소 카드, 첫 판 안내, 레벨업 3택1, 결과, 도움말.

## 1. 목표

- 판단에 필요한 정보(하트, 게임 시계, 쿨타임, 경험치, 부탁 진행)를 한눈에 보여준다.
- 화면 가운데(쥐 주변)는 비워 둔다.
- 죽은 판에서 무엇을 배울지 결과 화면과 도움말로 알려 준다. 영구 수치 강화가 없으므로(D-028) 막힌 플레이어를 돕는 것은 정보다.

## 2. 규칙

**화면 목록**
- 타이틀, 밤 선택, 플레이 중 HUD, 일시정지, 설정, 도움말, 레벨업 3택1, 결과.
- 인트로 카드와 엔딩 카드는 같은 텍스트 패널 하나를 쓴다. 새 요소 카드와 끝없는 밤 규칙 알림은 플레이 화면 위의 배너 하나를 쓴다.

**타이틀**
- 시작을 누르면 밤 선택 화면이 나온다. 인트로 카드 3장은 처음 1회만 나온다 (띄우는 때는 → [스토리](../진행/스토리.md)).

**밤 선택 화면**
- 밤 카드 7장. 카드마다 밤 번호, 별 3칸(생존 / 부탁 / 쫓아낸 수), 부탁 이름, 최단 기록. 잠긴 밤은 자물쇠만 보인다 (별 조건과 열림 순서는 → [캠페인](../진행/캠페인.md)).
- v1.1: 카드마다 눈송이 3칸. 눈송이를 눌러 열린 추위 단계 중 하나를 고른다 (기본 0). 7일째를 생존하면 끝없는 밤 카드가 열린다.
- 화면 아래에 겨울 창고 막대와 다음 해금까지 남은 양 (→ [겨울 창고](../성장/겨울_창고.md)).

**플레이 중**

| 위치 | 표시 |
|---|---|
| 왼쪽 위 | 하트 |
| 위 가운데 | 게임 시계 (12:00 → 6:00), 현재 단계, 그 아래 단계 문구 |
| 위 가운데 (단계 문구 아래) | 새 요소 카드, 끝없는 밤 규칙 알림 |
| 오른쪽 위 | 밤의 부탁 한 줄과 진행 (예: 깨진 컵 0/1), 완료하면 체크 |
| 아래 가운데 (경험치 바 위) | 첫 판 안내 문구 |
| 아래 가운데 | 경험치 바, 레벨 |
| 오른쪽 아래 | 대시·치즈 던지기 쿨타임 (모바일은 버튼 위에 표시) |
| 왼쪽 아래 (모바일) | 조이스틱 |

- 시계는 게임 시계 하나만 보인다. 아침 당김이 반영된 값이다. 실제 시간(기록)은 플레이 중에 보이지 않는다 (→ [시간 진행](../진행/시간_진행.md)).
- 고양이를 쫓아내면 시계 옆에 당겨진 시간이 "+N초"로 떠오른다.
- 함정 효과 범위와 쿨타임은 HUD가 아니라 맵 위의 함정에 늘 표시한다 (→ [함정 공통](../함정/함정_공통.md)). 고양이 상태 기호는 고양이 머리 위에 띄운다 (→ [고양이 공통](../적/고양이_공통.md)).

**모바일**
- 모바일은 쥐 중심 확대 카메라를 쓴다 (→ [맵](../월드/거실_주방_맵.md)). HUD 배치는 PC와 같고 조이스틱과 버튼만 더한다. 버튼 구성은 [기본조작](../플레이어/기본조작.md).
- 모바일 화면 작업은 v1.0 PC 뒤에 한다 (→ [프로젝트](../00_프로젝트.md)).

**텍스트 패널**
- 플레이 밖에서 화면 전체를 덮는 카드 한 장에 문구 하나. 문구는 [스토리](../진행/스토리.md).
- 인트로 카드 3장: 처음 1회. 띄우는 때와 넘기는 방법은 [스토리](../진행/스토리.md).
- 엔딩 카드 2장: 7일째를 처음 생존했을 때.

**새 요소 카드 (배너)**
- 화면 전체를 덮지 않는다. 위 가운데 단계 문구 아래에 띠 하나로 띄운다. 화면 가운데는 가리지 않는다.
- 게임을 멈추지 않는다. 게임 시계와 실제 시간도 계속 흐른다. 정해진 시간 뒤 사라진다.
- 밤이 시작될 때 그 밤의 새 요소 하나를 소개한다. 밤별 새 요소는 [캠페인](../진행/캠페인.md). 2일째 카드는 청소기와 미끼 내성을 함께 소개한다 (미끼를 무시하는 "×" 고양이는 청소기로 마무리).
- v1.1 끝없는 밤: 규칙이 하나 쌓일 때마다 규칙 이름을 같은 자리에 띄운다.

**첫 판 안내**
- 1일째 판에서 조건을 처음 만족할 때 하나씩 띄운다. 본 안내는 저장하고 다시 띄우지 않는다.
- 안내가 떠 있어도 게임은 멈추지 않는다. 새 안내가 뜨면 이전 안내는 바로 사라진다.

| 조건 | 문구 (PC) | 문구 (모바일) |
|---|---|---|
| 조작이 시작됨 | WASD 이동 · Ctrl 살금살금 · 발밑 원이 소리 범위 | 조이스틱을 살짝 밀면 살금살금 · 발밑 원이 소리 범위 |
| 고양이가 처음으로 쥐 쪽을 조사하거나 추적하기 시작함 | 클릭: 치즈를 던져 고양이를 딴 데로 | 던지기 버튼을 끌어 던질 곳을 정하세요 |
| 고양이가 처음으로 컵 범위 안에 들어감 | 노란 선 끝 스위치에서 E · 맞은 고양이는 스위치로 온다 | 노란 선 끝 스위치에서 상호작용 버튼 · 맞은 고양이는 스위치로 온다 |

**레벨업 3택1**
- 게임이 멈추고 카드가 가로로 나온다. 후보가 3장보다 적으면 있는 만큼만 나오고, 0장이면 이 화면을 띄우지 않는다 (→ [경험치·레벨업](../성장/경험치_레벨업.md), [업그레이드](../성장/업그레이드.md)).
- 카드마다 아이콘, 이름, 효과 한 줄, 현재 단계 / 최대 단계. 진화 카드는 진화 표시와 조건 카드 이름을 함께 보인다.
- PC: 마우스 클릭 또는 1·2·3 키. 모바일: 카드 터치.

**결과 화면**
- 승패 문구 (→ [스토리](../진행/스토리.md#문구)).
- 별 3칸. 이번 판에 새로 얻은 별을 표시한다.
- 실제 시간과 그 밤의 최단 기록, 쫓아낸 고양이 수, 모은 치즈 (이번 판에 얻은 경험치 합계), 도달 레벨.
- 창고 막대 증가와 새 해금, 새로 열린 밤. 창고 막대 옆에 치즈 더미 그림 (크기는 → [겨울 창고](../성장/겨울_창고.md)). 600에 닿으면 "겨울 준비 완료"를 띄운다.
- 다음 목표 한 줄 (예: 별 3까지 1마리).
- 패배하면 사망 원인 한 줄과 요령 한 줄. 원인은 마지막 하트를 잃을 때 잡은 고양이의 종류와 상태다. 요령은 아래 표에서 고른다.
- v1.1 끝없는 밤: 별 대신 06:00 이후 버틴 실제 시간과 최고 기록.
- 버튼: 다음 밤 (새 밤이 열렸을 때만), 다시 하기, 밤 선택.

| 고양이 | 원인 (그 고양이의 상태) | 요령 |
|---|---|---|
| 호기심냥 | 추적 | 달려서는 떨어지지 않는다. 미끼나 대시 잔상으로 끊는다 |
| 호기심냥 | 소리 조사 | 소리 원이 닿은 곳으로 온다. 가까이 있을 때는 살금살금 |
| 호기심냥 | 미끼로 가거나 먹는 중 | 미끼를 먹는 고양이도 바로 옆이면 잡는다. 한 걸음 떨어져 기다린다 |
| 게으름냥 | 기상 질주 | 큰 소리 지점으로 달려온다. 공이나 함정을 쓴 뒤 그 자리에서 벗어난다 |
| 게으름냥 | 추적 | 잔상으로 끊는다. 멀리 달아나 조용히 해도 놓친다 |
| 게으름냥 | 소리 조사·귀가 | 깨어 있는 게으름냥은 미끼를 먹고 그 자리에서 잠든다 |
| 게으름냥 | 미끼로 가거나 먹는 중 | 먹는 동안에도 잡힌다. 한 걸음 떨어져 기다린다 |
| 사냥꾼냥 | 덮치기 | 웅크리면 표시를 보고 꺾거나 대시. 피하면 추적이 끝난다 |
| 사냥꾼냥 | 추적 | 달리면 덮치지 않지만 떨어지지도 않는다. 공을 차거나 덮치기를 피한다 |
| 사냥꾼냥 | 소리 조사 | 미끼에 속지 않는다. 공 소리를 가장 먼저 쫓는다 |

**도움말**
- 조작과 기본 요령에 더해, 만난 고양이 종류의 반응 요약을 보여 준다. 만나지 않은 종류는 보이지 않는다. 만난 종류는 저장한다.
- 제목 화면과 일시정지 메뉴에서 열 수 있다. 실제 첫 키로 시작한 판의 초기 고양이와 이후 입장한 종류를 기록한다. 준비 화면·밤 해금만으로 공개하지 않는다. 기존 저장에는 이 기록이 없으므로 이후 만난 종류부터 추가한다.
- 종류마다 3줄이고, 셋째 줄은 추적을 끊는 열쇠다. 반응의 정의는 [고양이 종류](../적/고양이_종류.md).

| 고양이 | 1줄 | 2줄 | 3줄 (추적을 끊는 열쇠) |
|---|---|---|---|
| 호기심냥 | 소리가 난 곳을 조사한다 | 미끼를 보면 추적 중에도 간다. 먹은 고양이는 잠시 미끼를 무시한다 (×) | 미끼, 대시 잔상 |
| 게으름냥 | 발소리 원 안에서 수면이 줄고 밖에서는 천천히 회복한다. 접촉·원 안 대시는 즉시 깨운다 | 큰 소리는 기상 질주. 미끼 수면은 마지막 단계 제외, 수면 중 피해는 2배 | 잔상. 멀리 달아나 조용히 해도 놓친다 |
| 사냥꾼냥 | 미끼에 속지 않는다. 공 소리를 가장 먼저 쫓아 덮친다 | 멈추거나 다가오는 쥐를 덮친다. 웅크리면 착지 표시를 보고 피한다 | 공, 덮치기 피하기 |

## 3. 수치

| 항목 | 값 | 비고 |
|---|---|---|
| 레벨업 카드 입력 막는 시간 (오입력 방지) | 0.5초 | 초기값, 플레이테스트 후 확정 |
| 첫 판 안내 표시 시간 | 5초 | 초기값, 플레이테스트 후 확정 |
| 새 요소 카드 표시 시간 | 3초 | 초기값, 플레이테스트 후 확정. 끝없는 밤 규칙 알림도 같음. 게임과 시계는 멈추지 않음 |
| 사망 요령 표 | 10줄 | 게으름냥의 미끼 이동·먹기 피격을 별도로 안내 |
| 종류별 반응 요약 | 3줄 | |

모든 값은 초기값이며 인스펙터에서 조절하고, 플레이테스트 후 확정한다.

## 4. 근거

- 원문에는 HUD 정의가 없어 다른 기획서에서 플레이어에게 보여야 하는 값을 모았다.
- "+N초" (D-041): 쫓아내기가 곧 아침을 당긴다는 핵심 루프를 숫자로 바로 보여 준다. 시계를 둘 보여 주면 헷갈리므로 플레이 중에는 게임 시계만, 기록(실제 시간)은 결과 화면에만 둔다.
- 부탁 한 줄과 다음 목표 한 줄 (D-044): 밤마다 부탁이 고정이라 무엇을 노릴지 플레이 중과 결과 화면에서 같은 문장으로 보여 준다.
- 첫 판 안내 교체 (D-048): 떨어진 스위치와 "맞은 고양이가 스위치로 온다"는 직관과 반대인 규칙이라 처음 필요한 순간에 알려 준다. 함정 범위가 늘 보이므로 안내 조건을 '범위 표시'에서 '고양이가 범위에 들어감'으로 바꿨다.
- 새 요소 카드 (D-048): 밤마다 새 요소가 하나라 카드 한 장으로 충분하다. 2일째는 미끼 내성 때문에 2일째가 어려워지는 위험을 청소기 소개로 함께 푼다.
- 새 요소 카드를 배너로 (D-048): 플레이 중에 게임을 멈추지 않고 화면 전체를 덮으면 3초 동안 아무것도 못 본 채 시간이 흐른다. 배너로 띄워 화면 가운데를 비워 둔다. 시계를 멈추지 않으므로 실제 시간 제외 목록(일시정지·레벨업·결과)은 그대로다.
- 사망 원인과 요령, 도움말 반응 요약 (D-048): 반응표는 직관과 다른 칸이 많다(달려도 추적이 거의 안 끊김 등). 죽은 직후에 원인 하나와 대처 하나만 보여 준다.
- 매 판 배웅·맞이를 없애 판 사이 흐름이 결과 화면 → 다시 하기로 바로 이어진다 (D-048).
- 모바일 (D-050): 폰에서는 방 전체 화면의 고양이가 너무 작아 카메라만 따로 확대한다. HUD 배치는 PC와 같게 두어 화면을 두 벌 만들지 않는다.
- 모은 치즈 (D-022): 스토리 목표(겨울 치즈)를 결과 숫자로 보여준다.
- 카드 입력 0.5초 막기: 레벨업 순간 이동 키나 클릭을 누르고 있다가 원치 않는 카드를 고르는 일을 막는다.
