# HUD

<aside>
📌

**상태:** 초안

**관련 결정:** D-017, D-022, D-023

**한 줄 요약:** 플레이 중 화면 표시, 첫 판 안내, 인트로 카드, 레벨업 3택1 화면, 결과 화면.

</aside>

## 1. 목표

- 판단에 필요한 정보(하트, 남은 시간, 쿨타임, 경험치)를 한눈에 보여준다.
- 화면 가운데(쥐 주변)는 비워 둔다.

## 2. 규칙

**플레이 중**

| 위치 | 표시 |
|---|---|
| 왼쪽 위 | 하트 |
| 위 가운데 | 게임 시계 (12:00 → 6:00), 현재 단계, 그 아래 단계 문구 |
| 아래 가운데 (경험치 바 위) | 첫 판 안내 문구 |
| 아래 가운데 | 경험치 바, 레벨 |
| 오른쪽 아래 | 대시·치즈 던지기 쿨타임 (모바일은 버튼 위에 표시) |
| 왼쪽 아래 (모바일) | 조이스틱 |

- 함정 쿨타임은 HUD가 아니라 함정 위에 표시한다 (→ [함정 공통](../함정/함정_공통.md)).

**인트로 카드**
- 화면 전체를 덮는 카드 한 장에 문구 하나. 문구·넘기는 방법·순서는 [스토리](../진행/스토리.md).

**첫 판 안내**
- 게임을 켠 뒤 첫 판의 1단계에서만 띄운다. 각 안내는 조건을 처음 만족할 때 한 번만 뜬다.
- 안내가 떠 있어도 게임은 멈추지 않는다. 새 안내가 뜨면 이전 안내는 바로 사라진다.

| 조건 | 문구 (PC) |
|---|---|
| 배웅 연출이 끝나고 조작이 시작됨 | WASD 이동 · Ctrl 살금살금 · 발밑 원이 소음 범위 |
| 고양이가 처음으로 쥐 쪽을 조사하거나 추적하기 시작함 | 클릭: 치즈를 던져 고양이를 딴 데로 |
| 함정 효과 범위가 처음으로 표시됨 (→ [함정 공통](../함정/함정_공통.md)) | 고양이를 노란 범위에 세우고 E |

**레벨업 3택1**
- 게임이 멈추고 카드 3장이 가로로 나온다 (→ [업그레이드](../성장/업그레이드.md)).
- PC: 마우스 클릭 또는 1·2·3 키. 모바일: 카드 터치.

**결과 화면**
- 승패 문구 (→ [스토리](../진행/스토리.md#문구)), 생존 시간, 쫓아낸 고양이 수, 모은 치즈 (이번 판에 얻은 경험치 합계), 도달 레벨.
- 버튼: 다시 하기.

## 3. 수치

| 항목 | 값 |
|---|---|
| 레벨업 카드 입력 막는 시간 (오입력 방지) | 0.5초 |
| 첫 판 안내 표시 시간 | 5초 |

모든 값은 초기값이며, 플레이테스트 후 확정한다.

## 4. 근거

- 원문에는 HUD 정의가 없어 다른 기획서에서 플레이어에게 보여야 하는 값을 모았다.
- 첫 판 안내 (D-023): 1단계는 고양이가 적어 연습 구간 역할을 한다. 별도 튜토리얼 판 없이 핵심 동작 3개(소음, 미끼, 함정)를 처음 필요한 순간에 알려 준다. 게임을 멈추지 않아 흐름이 끊기지 않는다.
- 모은 치즈 (D-022): 스토리 목표(겨울 치즈)를 결과 숫자로 보여준다.
- 카드 입력 0.5초 막기: 레벨업 순간 이동 키나 클릭을 누르고 있다가 원치 않는 카드를 고르는 일을 막는다.

| 경험치 획득 | 바 차오름 | - | - |
