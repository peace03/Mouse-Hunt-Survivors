# 경험치·레벨업

<aside>
📌

**상태:** 초안

**관련 결정:** D-011, D-013, D-016, D-017, D-041, D-045

**한 줄 요약:** 치즈 조각을 주워 경험치를 모으고, 레벨업 때 카드 3장 중 1장을 고른다. 후보 카드가 없으면 레벨업이 없다.

</aside>

## 1. 목표

- 한 판에 5~7번 레벨업해서 판마다 다른 빌드를 만든다.
- 부스러기를 주우러 돌아다니게 해서 "소리를 무릅쓰고 움직일 이유"를 준다.
- 고양이를 쫓아내 아침을 당겨도 부스러기 공급이 줄지 않게 한다.

## 2. 규칙

- 치즈 조각은 두 종류다.
  - 부스러기: 판 시작 때 정해진 수가 깔리고, 이후 게임 시계 기준으로 일정 간격마다 생성 지점 중 무작위 위치에 생긴다. 사라지지 않는다.
  - 큰 치즈: 고양이가 퇴장할 때 그 자리에 떨어진다 (→ [고양이 공통](../적/고양이_공통.md)). 일정 시간 뒤 사라진다.
- 부스러기 생성 간격은 게임 시계를 따른다. 아침 당김으로 게임 시계가 앞당겨지면 그만큼 부스러기도 생긴다 (→ [시간 진행](../진행/시간_진행.md)).
- 큰 치즈의 경험치 = 그 고양이의 최대 체력 (→ [고양이 종류](../적/고양이_종류.md)).
- 쥐가 흡수 반경 안에 들어오면 치즈 조각이 쥐에게 끌려와 주워진다.
- 경험치가 필요량에 닿으면 레벨업한다. 게임이 멈추고 카드 후보 중 1장을 고른다 (→ [업그레이드](업그레이드.md)).
- 레벨업 선택 화면에 머문 시간은 기록(실제 시간)에 넣지 않는다 (→ [시간 진행](../진행/시간_진행.md)).
- 남은 경험치는 다음 레벨로 넘어간다. 한 번에 여러 레벨이 오르면 선택 화면이 연달아 나온다.
- 후보 카드가 0장이면 레벨업 화면을 띄우지 않는다. 보상도 없다. 하트 회복으로 대신하지 않는다.
- 필요량 = 기본 필요량 + 증가량 × (현재 레벨 − 1).
- 한 판에 모은 경험치 합계가 "모은 치즈"이고, 판이 끝나면 겨울 창고에 더해진다 (→ [겨울 창고](겨울_창고.md)).

## 3. 수치

| 항목 | 값 | 비고 |
|---|---|---|
| 부스러기 경험치 | 1 | |
| 판 시작 부스러기 | 6개 | |
| 부스러기 생성 간격 | 6초 (게임 시계) | |
| 맵에 동시에 있는 부스러기 최대 | 10개 | |
| 큰 치즈가 사라지는 시간 | 15초 (실제 시간) | |
| 큰 치즈 크기 | 부스러기의 1.5배 | 외형만 |
| 흡수 반경 | 1.5m | |
| 흡수 속도 | 9 m/s | |
| 기본 필요량 | 4 | |
| 레벨당 증가량 | 2 | |
| 판당 레벨업 목표 | 5~7번 | M0 측정으로 조정 |

필요량: 4, 6, 8, 10, 12, 14, 16 … (5번 누적 40, 6번 누적 54, 7번 누적 70)

공급 예상 (게임 시계 300초): 부스러기 약 35개(35) + 쫓아낸 고양이 4~6마리(평균 체력 약 4, 16~24) = 약 50~60 → 레벨업 5~6번. 1일째는 단계가 45초라 부스러기가 약 4분의 3이다.

모든 값은 초기값(인스펙터 조절)이며, 플레이테스트 후 확정한다.

## 4. 근거

- 원문의 "쫓겨난 고양이가 치즈를 떨어뜨림", "3택1"을 유지했다.
- 부스러기 (D-013): 퇴장 경험치만으로는 공급이 적고 판마다 차이가 크다. 부스러기가 고른 바닥을 깔아 준다.
- 부스러기를 게임 시계에 묶음 (D-041): 실제 시간에 묶으면 고양이를 잘 쫓아낼수록 판이 짧아져 레벨업이 줄어든다.
- 레벨업 5~7번 (D-045): 카드가 11장, 최대 단계 합이 18이다. 1일째에 처음부터 열린 카드만으로도 최대 단계 합이 8이라 캠페인에서는 후보가 0장이 되지 않는다.
- 후보 0장이면 레벨업 없음 (D-045): 하트 회복으로 대신하면 끝없는 밤에서 회복이 끝없이 생긴다.
- 큰 치즈 15초: 쫓아낸 직후 근처 고양이를 무릅쓰고 주울지, 안전을 택할지 고르게 한다.
