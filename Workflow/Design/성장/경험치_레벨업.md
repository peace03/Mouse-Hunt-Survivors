# 경험치·레벨업

<aside>
📌

**상태:** 초안

**관련 결정:** D-011, D-013, D-017

**한 줄 요약:** 치즈 조각을 주워 경험치를 모으고, 레벨업 때 업그레이드 3개 중 1개를 고른다.

</aside>

## 1. 목표

- 한 판에 6~8번 레벨업해서 판마다 다른 성장 경로를 만든다.
- 부스러기를 주우러 돌아다니게 해서 "소음을 무릅쓰고 움직일 이유"를 준다.
- 1일차 구현 대상이다 (치즈 → 레벨업 → 3택1 UI).

## 2. 규칙

- 치즈 조각은 두 종류다.
  - 부스러기: 맵의 생성 지점 중 무작위 위치에 주기적으로 생긴다. 사라지지 않는다.
  - 큰 치즈: 고양이가 퇴장할 때 그 자리에 떨어진다 (→ [고양이 공통](../적/고양이_공통.md)). 일정 시간 뒤 사라진다.
- 큰 치즈의 경험치 = 그 고양이의 최대 체력 (→ [고양이 종류](../적/고양이_종류.md)).
- 쥐가 흡수 반경 안에 들어오면 치즈 조각이 쥐에게 끌려와 주워진다.
- 경험치가 필요량에 닿으면 레벨업한다. 게임이 멈추고 업그레이드 3개 중 1개를 고른다 (→ [업그레이드](업그레이드.md)).
- 남은 경험치는 다음 레벨로 넘어간다. 한 번에 여러 레벨이 오르면 선택 화면이 연달아 나온다.
- 필요량 = 기본 필요량 + 증가량 × (현재 레벨 − 1).

## 3. 수치

| 항목 | 값 |
|---|---|
| 부스러기 경험치 | 1 |
| 부스러기 생성 간격 | 6초 |
| 맵에 동시에 있는 부스러기 최대 | 10개 |
| 큰 치즈가 사라지는 시간 | 15초 |
| 흡수 반경 | 1.5m |
| 기본 필요량 | 4 |
| 레벨당 증가량 | 2 |

필요량: 4, 6, 8, 10, 12, 14, 16, 18 … (7번 레벨업 누적 70, 8번 누적 88)

공급 예상 (5분): 부스러기 약 35개(35) + 퇴장 약 10마리(평균 4, 40) = 약 75 → 레벨업 7번 안팎.

모든 값은 초기값이며, 플레이테스트 후 확정한다.

## 4. 근거

- 원문의 "쫓겨난 고양이가 치즈를 떨어뜨림", "한 판 6~8번 레벨업", "3택1"을 유지했다.
- 부스러기 추가 (D-013): 퇴장 경험치만으로는 공급이 적고 판마다 차이가 크다. 부스러기가 고른 바닥을 깔아 준다.
- 큰 치즈 15초: 쫓아낸 직후 근처 고양이를 무릅쓰고 주울지, 안전을 택할지 고르게 한다.

## 5. 연출·피드백

| 시점 | 화면 | 소리 | 애니메이션 |
|---|---|---|---|
| 부스러기 생성 | 노란 반짝임 | - | - |
| 끌려옴 | 쥐에게 날아옴 | 뾱 | - |
| 큰 치즈 사라지기 3초 전 | 깜빡임 | - | - |
| 레벨업 | 쥐 주변 빛, 게임 멈춤, 카드 3장 등장 (→ [HUD](../UI/HUD.md)) | 레벨업 효과음 | 치즈 먹기 (볼 빵빵) |

## 6. 연관 기능

- [고양이 공통](../적/고양이_공통.md): 퇴장 시 큰 치즈
- [업그레이드](업그레이드.md): 레벨업 선택지, 흡수 범위 강화
- [맵](../월드/거실_주방_맵.md): 부스러기 생성 지점
- [HUD](../UI/HUD.md): 경험치 바, 3택1 화면
