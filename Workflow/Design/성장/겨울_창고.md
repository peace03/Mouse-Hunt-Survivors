# 겨울 창고

<aside>
📌

**상태:** 초안

**관련 결정:** D-027, D-028, D-046, D-047

**한 줄 요약:** 판마다 모은 치즈가 창고에 쌓이고, 50·150·300에서 카드가 하나씩 열린다. 600에서 겨울 준비가 끝난다. 영구 수치 강화는 없다.

</aside>

## 1. 목표

- 지든 이기든 판이 끝나면 남는 것이 있게 한다.
- 스토리 목표("겨울을 날 치즈")를 실제 진행 막대로 보여 준다.
- 해금은 고를 수 있는 카드를 늘릴 뿐이다. 모찌를 영구히 강하게 만들지 않는다.

## 2. 규칙

- 판이 끝나면 그 판에 모은 치즈(이번 판 경험치 합계, → [경험치·레벨업](경험치_레벨업.md))가 창고에 더해진다.
  - 승리: 전부 더한다.
  - 패배: 절반을 더한다 (내림).
  - 끝없는 밤은 늘 패배로 끝나므로 절반을 더한다 (→ [캠페인](../진행/캠페인.md)).
- 창고 양은 줄지 않는다. 치즈를 써서 사는 상점은 없다.
- 창고가 단계 기준에 닿으면 그 단계의 카드가 열린다. 한 번 열린 카드는 계속 열려 있다.
- 잠긴 카드는 레벨업 후보에 나오지 않는다 (→ [업그레이드](업그레이드.md)).
- 창고 막대와 치즈 더미 그림은 해금이 끝난 뒤에도 600까지 계속 커진다. 600에 닿으면 "겨울 준비 완료"다.
- 영구 수치 강화(이동 속도, 소리 반경, 하트 등을 판 밖에서 올리는 것)는 없다.
- 창고 누적량은 저장된다 (→ [캠페인](../진행/캠페인.md)).

## 3. 수치

| 창고 단계 | 누적 치즈 | 해금 |
|---|---|---|
| 1 | 50 | 카드: 메아리 대시 |
| 2 | 150 | 카드: 쫀득한 치즈 |
| 3 | 300 | 진화 카드: 그림자 대시 |
| 완료 | 600 | 겨울 준비 완료 (막대와 치즈 더미 최대) |

나머지 카드는 처음부터 열려 있다 (→ [업그레이드](업그레이드.md)).

| 항목 | 값 | 비고 |
|---|---|---|
| 승리 시 창고에 더하는 비율 | 100% | |
| 패배·끝없는 밤 시 창고에 더하는 비율 | 50% (내림) | |
| 치즈 더미 크기 | 누적량에 비례, 600에서 최대 | |

- 기준 계산: 승패가 섞이면 판당 약 50개를 모은다고 보면 1, 3, 6, 12판째에 각 단계에 닿는다. 판당 치즈를 측정해 모든 기준을 같은 비율로 바꾼다.

모든 값은 초기값(인스펙터 조절)이며, 플레이테스트 후 확정한다.

## 4. 근거

- 해금만 (D-028): 영구 수치 강화가 쌓이면 소리 관리라는 핵심 긴장이 무너지고, 실력보다 반복 횟수가 승패를 가른다. 카드 해금은 판 안의 선택지를 넓힐 뿐 힘의 상한은 그대로다.
- 해금 3단계 (D-046): 카드 풀이 11장으로 줄었다. 잠그는 카드도 은신·잔상 방향과 미끼 방향에 하나씩, 그리고 그 진화만 남겼다. 해금은 6판쯤에 끝나고, 막대는 12판쯤까지 커져 스토리 목표를 이어 간다.
- 처음에 잠그는 카드: 메아리 대시·쫀득한 치즈·그림자 대시는 잔상과 미끼를 익힌 뒤에 의미가 생긴다. 처음 하는 사람의 선택지를 줄여 판단 부담을 덜어 준다.
- 상점 없이 자동 해금: 쓰는 화면과 가격 균형을 만들 필요가 없다. 창고 막대 하나로 끝난다.
- 패배 절반: 져도 진행되지만, 이기는 쪽이 확실히 이득이다. 끝없는 밤은 승리가 없으므로 패배 비율을 쓴다.
- 치즈 더미: 그림 하나를 크기만 바꿔 쓴다. 새 모델링 없이 쌓이는 느낌을 준다.
