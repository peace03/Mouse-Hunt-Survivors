# 업그레이드

<aside>
📌

**상태:** 초안

**관련 결정:** D-011, D-015, D-017, D-024

**한 줄 요약:** 레벨업 때 고르는 16개 강화(함정 6, 쥐 5, 치즈 3, 시너지 2).

</aside>

## 1. 목표

- 판마다 다른 플레이 방향(함정 위주, 은신 위주, 미끼 위주)을 고르게 한다.

## 2. 규칙

- 레벨업하면 후보 중 무작위 3개가 나오고 1개를 고른다 (→ [경험치·레벨업](경험치_레벨업.md)).
- 업그레이드마다 최대 단계가 있다. 최대 단계에 이른 것은 후보에서 빠진다.
- 시너지 업그레이드는 조건을 갖춘 뒤에만 후보에 나온다.
- 후보가 3개보다 적으면 있는 만큼만 보여준다. 후보가 0개면 하트 1개 회복으로 대신한다.

## 3. 수치

**함정 강화 (6)**

| 이름 | 효과 (1단계당) | 최대 단계 |
|---|---|---|
| 컵: 더 오래 기절 | 컵 기절 +1초 | 3 |
| 컵: 더 넓게 | 컵 낙하 반경 +0.5m | 3 |
| 청소기: 빠른 충전 | 청소기 쿨타임 −3초 | 3 |
| 청소기: 긴 청소 | 청소기 작동 시간 +2초 | 3 |
| 선풍기: 빠른 충전 | 선풍기 쿨타임 −3초 | 3 |
| 선풍기: 센 바람 | 바람 길이 +1.5m | 3 |

**쥐 능력 (5)**

| 이름 | 효과 (1단계당) | 최대 단계 |
|---|---|---|
| 조용한 발 | 살금살금 속도 +0.4 m/s | 3 |
| 솜털 발바닥 | 모든 소음 반경 −10% | 3 |
| 날쌘 몸 | 대시 쿨타임 −0.7초 | 3 |
| 하트 +1 | 최대 하트 +1, 즉시 1개 회복 (최대 하트 상한 5) | 2 |
| 질긴 꼬리 | 피격 후 무적 +0.5초 | 2 |

**치즈 (3)**

| 이름 | 효과 (1단계당) | 최대 단계 |
|---|---|---|
| 멀리 던지기 | 던지기 사거리 +2m | 3 |
| 쫀득한 치즈 | 미끼 먹는 시간 +1초 | 3 |
| 큰 주머니 | 흡수 반경 +0.75m | 3 |

**시너지 (2)**

| 이름 | 효과 | 조건 | 최대 단계 |
|---|---|---|---|
| 바람 맞은 고양이 | 선풍기 바람에 닿은 고양이는 5초 동안 컵 피해 2배 | 컵 또는 선풍기 강화 1개 이상 | 1 |
| 치즈 묻은 청소기 | 청소기가 지나간 경로에 치즈 흔적이 6초 남는다. 흔적 3m 안의 고양이는 흔적을 따라 청소기 쪽으로 간다 | 청소기 강화 1개 이상 | 1 |

모든 값은 초기값이며, 플레이테스트 후 확정한다.

## 4. 근거

- 분류와 개수(6/5/3/2), 항목은 원문 그대로다.
- 함정 강화 함정별 2개 (D-015): 컵은 한 방의 위력이 성격이라 기절·범위, 청소기와 선풍기는 자주·오래 쓰는 것이 성격이라 쿨타임·지속.
- 하트 +1 최대 2단계: 최대 하트 5와 맞춘다 (→ [체력](../플레이어/체력.md)).
- 시너지 조건: 관련 함정을 안 쓰는 판에 시너지가 나오면 버리는 선택지가 된다.

## 5. 연출·피드백

| 시점 | 화면 | 소리 | 애니메이션 |
|---|---|---|---|
| 카드 표시 | 아이콘, 이름, 효과 한 줄, 현재 단계 / 최대 단계 | 카드 넘김 | - |
| 선택 | 고른 카드 확대 후 사라짐, 게임 재개 | 확인음 | - |

## 6. 연관 기능

- [기본조작](../플레이어/기본조작.md), [체력](../플레이어/체력.md), [치즈 던지기](../플레이어/치즈_던지기.md): 쥐·치즈 강화 대상
- [컵 밀기](../함정/컵_밀기.md), [로봇청소기](../함정/로봇청소기.md), [선풍기](../함정/선풍기.md): 함정 강화 대상
- [HUD](../UI/HUD.md): 카드 화면

## 7. 확인 필요

- 시너지 "바람 맞은 고양이": 선풍기가 컵(식탁)이 아니라 청소기 경로를 향하게 되어(D-024) 5초 안에 컵까지 가기 어렵다. 추천: "5초 동안 청소기 피해 2배"로 변경.
