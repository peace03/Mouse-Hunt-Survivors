# 디버그

<aside>
📌

**상태:** 초안

**관련 결정:** D-017

**한 줄 요약:** 테스트·디버그 키 예약표. 새 디버그 키는 이 표에 먼저 적고 쓴다.

</aside>

## 1. 목표

- 5분짜리 판을 처음부터 다시 하지 않고도 원하는 상황을 바로 만들어 확인한다.

## 2. 규칙

- 디버그 키는 에디터와 개발 빌드에서만 동작한다. 정식 빌드에는 들어가지 않는다.
- 새 디버그 키는 아래 예약표에 먼저 적는다. 게임 키([기본조작](../플레이어/기본조작.md))와 겹치면 안 된다.

## 3. 수치

### 키 예약표

| 키 | 동작 | 상태 |
|---|---|---|
| F1 | 디버그 정보 표시 (FPS, 고양이 상태, 소음 반경) | 예약 |
| F2 | 다음 단계로 시간 건너뛰기 (+60초) | 예약 |
| F3 | 즉시 레벨업 | 예약 |
| F4 | 쥐 무적 켜기/끄기 | 예약 |
| F5 | 맵의 고양이 모두 퇴장 | 예약 |
| F6 | 모든 함정 쿨타임 초기화 | 예약 |

상태: `예약`(아직 구현 안 함) / `사용`(구현됨).

## 4. 근거

- F 키는 게임 키와 겹치지 않는다.
- 시간 건너뛰기·즉시 레벨업: 후반 단계와 업그레이드를 확인할 때마다 5분씩 플레이하지 않게 한다.
