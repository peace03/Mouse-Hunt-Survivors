# 2026-10-15 스토리와 한 판 흐름

## 상황

- 사용자가 "스토리와 게임 플레이 방식을 실현 가능한 수준으로 구체화"를 요청했다.
- 규칙·수치는 기능별 기획서에 이미 있지만 스토리 문서는 없었다. 그래서 "고양이가 왜 다시 들어오나", "왜 6시에 이기나", "왜 치즈를 모으나"의 설명이 비어 있었다.
- 마감(10/21)과 1인 작업량을 기준으로, 스토리는 텍스트로만 전달하고 새 시스템은 만들지 않는 방향으로 제안했다.
- 맵 배치의 `확인 필요` 4건(선풍기 방향, 컵 개수, 가구 밑 통로, 청소기 경로)도 함께 물었다.

## 고민한 선택지

| 문제 | 선택지 | 고른 것 | 이유 |
|---|---|---|---|
| 스토리 설정 | A 집사·펫도어·알람·겨울 치즈 / B 한 줄 소개만 / C 다른 설정 | A + 처음과 끝에 가족 배웅·맞이 (사용자 추가) | 펫도어 하나로 출입구·퇴장·재입장이, 알람 하나로 6시 승리가 설명된다. 가족은 치즈를 모으는 이유를 눈에 보이게 한다 |
| 스토리 전달 | 카드 3장 + 단계 문구 / 단계·승패 문구만 / 정지 일러스트 컷신 | 카드 3장 + 단계 문구 | 문구 데이터와 카드 UI 하나로 끝난다. 일러스트 작업이 없다 |
| 첫 판 안내 | 1단계 상황별 안내 3개 / 없음 / 별도 튜토리얼 판 | 상황별 안내 3개 | 1단계는 이미 고양이가 적어 연습 구간 역할을 한다. 별도 판을 만들 시간이 없다 |
| 선풍기 위치 | 주방으로 옮겨 컵 낙하 지점을 향함 / 소파 옆 그대로 두고 청소기 경로를 향함 | 소파 옆 그대로, 청소기 경로를 향함 | 사용자 선택. 원문 배치를 지킨다 |
| 나머지 맵 3건 | 제안대로 / 모델링 뒤 결정 | 제안대로 | 컵 1개, 가구 밑 통로 없음, 청소기는 고리 경로 |

## 결정 (D-번호)

- D-020 스토리 A안: 집사가 잠든 밤에는 고양이들이 집을 차지한다. 벽 속 쥐 모찌는 겨울을 날 치즈를 모은다. 고양이 출입구는 펫도어이고, 6시 알람이 울리면 고양이들이 밥그릇으로 달려가 승리한다. 함정은 고양이를 놀라게 할 뿐 다치게 하지 않는다. 패배하면 모찌가 쥐구멍으로 도망친다.
- D-021 게임의 처음과 끝에 모찌가 가족의 배웅을 받으며 쥐구멍을 나서고, 가족의 맞이를 받으며 들어온다.
- D-022 스토리 전달: 인트로 텍스트 카드 3장(스킵 가능), 단계 전환 문구 5개, 승패 문구, 결과 화면에 "모은 치즈".
- D-023 첫 판 안내: 1단계에서 상황별 안내 문구 3개(이동·소음 / 치즈 던지기 / 함정 작동)를 처음 해당 상황에서 한 번씩 띄운다.
- D-024 선풍기는 소파 옆 원래 자리에 두고 청소기 경로 쪽을 향하게 한다.
- D-025 컵 함정 1개(식탁), 가구 밑 쥐 전용 통로 없음, 청소기 경로는 충전독 → 중앙 공터 → 쥐구멍 ② 앞 → 러그 → 소파 앞 → 충전독 고리.
