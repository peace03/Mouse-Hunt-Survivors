# 2026-10-21 확인 필요 답변

## 상황

- 재설계를 기획서에 반영한 뒤 남은 `확인 필요` 8건과 추가 질문에 사용자가 답했다.
- 캠페인의 추위 2단계 고장 함정 배정, 새 요소 카드 문구, 끝없는 밤 알림 문구(에이전트 초안)는 사용자가 "좋네"로 승인했다. 문서는 그대로 둔다.

## 결정 (D-번호)

- D-054 리깅은 AI가 한다. 애니메이션은 AI가 추천하거나 사용자가 구해 온다. 일정은 따로 잡지 않는다.
- D-055 디버그 키를 쓴 판도 아침 당김·큰 치즈·쫓아낸 수·저장 기록을 평소처럼 처리한다.
- D-056 맵의 정확한 좌표는 구현할 때 AI가 레이아웃 자동 검사를 통과하는 자리로 정한다.
- D-057 구르는 중인 공은 다시 찰 수 없다.
- D-058 스위치를 누르는 0.5초 동안 쥐가 움직이면 누르기가 취소된다.
- D-059 꺼진 함정은 쥐가 스위치 4m 안에 오면 범위와 연결선을 회색으로 표시한다.
- D-060 BGM이 있고 VARCO로 생성한다. 외부 음원 금지 규칙은 효과음에만 적용한다.
- D-061 공 차기는 도착 위치를 정한다. PC는 커서 지점, 모바일은 상호작용 버튼을 누른 채 드래그한 지점이다(최대 6m). 사용자 제안이고, 플랫폼 규칙을 맞추려고 PC도 같게 했다.
- D-062 노랑 규칙을 상호작용 대상(장난감 공)까지 넓힌다.
- D-063 진화 확정 칸을 없앤다. 조건을 채운 진화 카드는 다른 카드와 같이 무작위 후보로 나온다.
