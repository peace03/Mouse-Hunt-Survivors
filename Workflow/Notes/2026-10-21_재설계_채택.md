# 2026-10-21 재설계 채택

## 상황

- 2026-10-20 사용자 요청: "현재 기획이 최소한의 리소스로 짜임새 있고 재미있는 장기 플레이 게임이 되도록 기획해봐."
- 멀티 에이전트 재설계를 했다. 과정: 분석 → 4관점 설계 → 비판 → 심사 → 종합 → 검토·보완 4회. 심사 우승은 '리소스 최소화' 안이다. 제안서는 [재설계안](2026-10-21_재설계안.md).
- 사용자가 제안서의 열린 질문 8개에 답했다.

## 결정 (D-번호)

- D-036 재설계안을 기획 기준으로 채택한다. 기둥 5개(소리가 곧 규칙 / 고양이마다 열쇠 하나 / 누르는 자리와 맞히는 자리는 다르다 / 쫓아내면 아침이 온다 / 새 모델 대신 데이터로 늘린다), v1.0·v1.1 범위, 로드맵 M0~M6, 버릴 순서.
- D-037 소리 체계: 소리 5종(일반, 큰 소리, 잔상, 미끼, 공). 고양이는 목표를 하나만 가지며 종류별 우선순위와 목표 종료 규칙을 따른다. 추적 중 쥐 자리에서 난 소리는 놓침 타이머를 리셋한다. 전역 소음 배율은 쥐 몸 소리에만 곱하고, 발소리 배율(하한 0.6)은 그 앞에서 계산한다.
- D-038 쥐 이동: 달리기 5.5m/s. 대시는 '잔상'이다(시작 지점에 9m 잔상 소리, 대시 중과 직후 0.5초는 이동 소리 없음).
- D-039 미끼: 먹는 시간 1.5초. 미끼를 먹은 고양이는 30초 동안 미끼에 다시 속지 않는다(1일째는 없음). 미끼로 가거나 먹는 중에도 0.8m 안이면 잡는다.
- D-040 함정 스위치: 모든 스위치는 효과 범위 밖에 있다(컵은 낙하 중심에서 6m). 누르기 0.5초 동안 쥐 자리에서 3m 소리가 난다. 효과 범위는 늘 보인다. 맞은 고양이는 기절이 끝나면 그 스위치를 조사한다. 청소기는 경로 한 바퀴를 돌고, 충전독 3m 안에서는 타격하지 않는다.
- D-041 아침 당김: 고양이를 쫓아낼 때마다 게임 시계가 최대 체력 × 2초 앞당겨진다. 단계·증원·부스러기는 게임 시계, 쿨타임·재입장·내성은 실제 시간을 따른다. 기록은 Playing 단계의 실제 시간이다.
- D-042 고양이 3종 반응표: 호기심냥은 미끼, 게으름냥은 잠(잠든 채 맞으면 피해 ×2, 미끼로 다시 재움), 사냥꾼냥은 공(공을 가장 먼저 덮침, 예측 덮치기, 빗나가면 헛디딤).
- D-043 장난감 공: 4일째부터. E로 차면 커서 방향으로 3m/s, 최대 6m 직선. 구르는 동안 공 소리 4m, 스스로 멈추면 9m 큰 소리. 12초 동안 아무도 차지 않으면 시작 자리로 돌아간다.
- D-044 캠페인 7밤: 밤마다 새 요소 1개, 밤마다 부탁 1개를 고정한다. 별 3 = 쫓아낸 수 N 이상으로 생존. 6일째는 컵 고장. 비 오는 밤은 보류한다. 저장은 원기록만 남긴다.
- D-045 카드 11장(기본 8 + 진화 3). 후보가 0장이면 레벨업이 없다(하트 회복 대체 삭제).
- D-046 겨울 창고 해금 3단계(50 메아리 대시, 150 쫀득한 치즈, 300 그림자 대시). 막대와 치즈 더미는 600까지 커진다.
- D-047 v1.1: 추위 1~3(누적 규칙, 밤별 사다리), 컵 위치 무작위(추위에서만), 끝없는 밤('집사가 늦잠 잔 일요일'). 대왕냥은 보류한다.
- D-048 연출: 매 판 배웅·맞이를 없앤다. 인트로 카드 3장(처음 1회), 승리는 알람 + 페이드, 엔딩 카드 2장(+아기 쥐 1컷). 밤 시작 때 '새 요소' 카드, 결과 화면에 사망 원인과 요령 한 줄, 첫 판 안내 3개는 소리 원 / 미끼 / 떨어진 스위치.
- D-049 아트: 고양이는 메시 1개(부품 분리, 재질 슬롯 3개 단색)로 3종을 만든다. 새 기능 소품은 선풍기 1개. 쥐와 고양이는 리깅하고 애니메이션을 적용한다(사용자 결정). 모델·애니메이션이 준비되기 전에는 코드 움직임으로 대신한다.
- D-050 카메라: PC는 방 전체 고정 직교 카메라. 모바일만 쥐 중심 확대·따라가기, 두 손가락으로 전체 보기 전환. 모바일 작업은 v1.0 PC 뒤다.
- D-051 장기 목표는 중앙값 5~8시간 완결형 + 기록 모드(추위, 끝없는 밤)다. 30시간 확장은 v1.1 뒤 판 수 기록을 보고 따로 정한다.
- D-052 외부 플레이테스터는 온라인으로 소수 모집한다(비공개 링크). 밤별 밸런스 목표로 마일스톤을 닫는다.
- D-053 검증 장치: 레이아웃 자동 검사, 반응표 검사, 판마다 측정 CSV, 디버그 키(F1 단계 넘기기, F2 +30초, F3 모든 고양이 퇴장).
