# 코드 컨벤션 (Unity C#)

> Unity 6000.6.0f1, URP. 프로젝트 폴더 `MidnightMouse/`.

## 1. 이름

- 클래스·메서드 `PascalCase`, private 필드 `_camelCase`, bool은 `IsDead`·`_canJump`.
- 파일 하나에 클래스 하나, 파일명 = 클래스명.
- 모든 클래스는 `namespace MidnightMouse` (D-007). 하위 구분이 필요하면 `MidnightMouse.Cats`처럼 붙인다.

## 2. 인스펙터

- `public` 대신 `[SerializeField] private`.
- **기획서의 수치는 전부 인스펙터에 노출한다 (D-016).** 코드에 숫자를 박지 않는다. 기본값은 기획서의 초기값과 같게 한다.
- 노출되는 값마다 한국어 `[Tooltip]`에 **무엇 · 단위 · 올리면/내리면 · 권장 범위**를 쓴다. 숫자는 가능하면 `[Range]`.
  `[Tooltip("달리기 속도(m/s). 올리면 고양이를 쉽게 따돌림. 권장 5~8.")]`
- 여러 개체가 같은 값을 쓰면(고양이 종류별 수치, 함정별 수치, 업그레이드 목록) `ScriptableObject` 하나에 모아 에셋으로 조절한다.

## 3. 주석 (한국어)

- 클래스 위에 역할 한 문장과 붙이는 곳(어느 오브젝트에 다는지).
- 모든 메서드에 `/// <summary>`.
- 메서드 안은 `// 1) … // 2) …` 단계 주석. 숫자·조건·우회에는 이유를 쓴다.
- 코드를 그대로 읽어 주는 주석과 옛 코드 주석 처리는 금지.

## 4. 설계

- 한 클래스는 한 가지 일 (설명에 "그리고"가 없게). 상속보다 컴포넌트 조합.
- 새 종류가 늘어날 곳(함정, 고양이 행동, 업그레이드 효과)만 인터페이스·다형성.
- 구현체가 하나뿐인 인터페이스, "나중에 쓸지도" 추상화는 만들지 않는다.
- 모델이 아직 없으면 임시 도형으로 만들고, 모델은 자식 오브젝트로 붙여 교체만 하면 되게 한다.

## 5. 성능 (PC 144FPS = 프레임당 6.9ms, D-004)

- `GetComponent`·`Camera.main` 캐시.
- `Update`에서 `new`·LINQ·문자열 연결 금지.
- 반복 생성 오브젝트(치즈 조각, 미끼 치즈, 이펙트, 재입장 고양이)는 풀링.
- `Physics.OverlapSphereNonAlloc` 등 `NonAlloc` + 레이어 마스크 + 거리 제한. 소음 전달은 매 프레임 전수 검사 대신 소음이 날 때만 한다.
- `Animator.StringToHash`·`Shader.PropertyToID` 저장. `SendMessage` 금지.
- 최적화한 곳에는 이유 주석.

## 6. 입력

- Input System 패키지를 쓴다.
- 게임 키의 원본은 [기본조작](../Design/플레이어/기본조작.md). 테스트·디버그 키는 [디버그](../Design/디버그/디버그.md)의 키 예약표에 먼저 적고 쓴다.
- 코드에서는 `[SerializeField] private Key _key = Key.Q;`처럼 노출하고, 디버그 코드는 `#if UNITY_EDITOR || DEVELOPMENT_BUILD`로 감싼다.

## 7. 태그·레이어

- 쓰는 태그·레이어 목록은 [00_프로젝트](../Design/00_프로젝트.md)에 둔다.
- 코드에서 새 태그를 쓰기 전에 Unity 설정에 등록됐는지 확인한다 (등록 안 된 태그 비교는 매번 에러).

## 8. 기타

- **직렬화 필드 이름을 바꾸면** `[FormerlySerializedAs("옛이름")]`. 안 하면 프리팹·씬에 저장된 값이 사라진다.
- 인스펙터 연결이 비면 `Awake`에서 `Debug.LogError`로 어디가 비었는지 알린다.
- 불필요한 `Debug.Log`는 커밋 전에 지운다.
