# 선별 임포트한 외부 리소스

2026-10-21에 요청한 무료 패키지 5개에서 현재 맵에 필요한 원본 파일 44개(73,780,087바이트, 약 70.4MiB)를 골라 임포트했다. 원본 GUID를 유지했으며, 모든 파일의 공통 경로는 `MidnightMouse/Assets/_Project/Art/ThirdParty/`이다. 후속 요청에 따라 `SampleScene`과 게임용 고양이 프리팹에도 모델을 적용했다.

## 씬 적용

- 고양이 7마리는 `Environment/Prefabs/CuriousCat.prefab`의 `Visual/ImportedCat`을 공유한다. 대기·달리기를 실제 이동 속도로 전환하고 일시정지 시 재생도 멈춘다. 루트 이동은 기존 NavMeshAgent가 담당한다. 전용 걷기를 준비하기 전까지 달리기 클립의 재생 속도를 낮춰 걷기를 대신한다.
- 원본 클립은 한 번 재생하는 설정이어서 `Environment/Animations/CatIdle.anim`, `CatRun.anim`에 반복 설정을 적용하고 `CatLocomotion.overrideController`로 연결했다. 외부 원본 클립·컨트롤러는 그대로 둔다.
- `Environment_NightLivingRoom` 아래 `Sofa/ImportedSofa`, `DiningTable/ImportedTable`, `ImportedRug`, `ImportedFridge`로 배치했다. 조리대·싱크대는 `Kitchen` 아래에 있다. 기존 충돌체 14개와 길찾기 데이터를 유지하며, 재배치한 의자에는 별도의 충돌체와 NavMeshObstacle을 추가했다.
- `Kitchen/ImportedFan`은 조리대 위에 둔 정적 모델이다. 현재 게임의 함정 종류는 컵·청소기만 있으므로 바람·타격·날개 회전은 연결하지 않았다.
- 기존 평가 씬을 다시 만들면 같은 모델 적용이 자동 실행된다. 기존 씬만 갱신할 때는 `MidnightMouse > 받은 리소스 적용` 메뉴를 쓴다. 메뉴는 모델 배치를 다시 맞추므로 이후 수동으로 바꾼 모델의 위치·크기는 재적용 시 초기화된다.
- 외부 패키지 원본은 수정하지 않았다. 게임 씬 인스턴스의 크기·회전만 바꿨다. 적용 및 검증의 실제 결과는 [적용 기록](../Tasks/resource-apply/결과.md)에 남긴다.
- 러그는 바닥에서 0.005m 띄우고 두께를 0.01m로 맞췄다. 윗면을 0.015m로 낮춰 모찌 소음·함정 범위 선이 러그에 묻히지 않게 한다. 범위 판정 수치와 선의 렌더링 설정은 유지한다.

## 방 꾸미기 추가 적용

2026-10-22 사용자가 제공한 ZIP에서 화분·책·그릇·과일과 표면 텍스처만 추가했다. [선별 파일 및 원본 해시](../Tasks/room-art-pass/imports.json), [적용·검증 기록](../Tasks/room-art-pass/결과.md)을 따로 남긴다.

| `Art/ThirdParty/Kenney/Furniture/` | `pottedPlant.fbx`, `books.fbx`. 양쪽 화분·식탁 책·수납장 책에 사용 |

위 경로는 `MidnightMouse/Assets/_Project/` 아래다. 바닥 판재의 렌더러는 숨기고 기존 바닥에 나무 텍스처를 적용한다. 벽지와 식탁 천은 기존 오브젝트에 적용한다. 외부 원본 재질은 게임용 재질 조정을 위해 덮어쓰지 않는다.

의자 두 개는 식탁 중심에서 앞뒤로 1.65m 떨어져 서로 마주 본다. 좌판 앞부분만 상판 아래로 넣고 등받이는 밖으로 뺐다. 의자 충돌체는 모델 크기에 맞추며, NavMeshObstacle의 carving이 고양이 경로에서 의자 영역을 제외한다. 창문은 기존 구조에 상단 몰딩·창턱 아래 장식·손잡이를 추가했다. 싱크대는 기존 모델을 유지하고 기존 수전을 싱크 중심에 복구했다.

Kenney 두 팩과 ambientCG 텍스처는 CC0다. [Furniture Kit](https://kenney.nl/assets/furniture-kit), [Food Kit](https://kenney.nl/assets/food-kit), [ambientCG 라이선스](https://docs.ambientcg.com/license/). Kenney 라이선스 파일은 각 폴더에 보관한다.

## 애니메이션 호환 범위

- PolyOne 기본 대기·달리기: 고양이 프리팹의 뼈 경로 30개 중 30개가 일치한다.
- Rip Vertices 추가 동작: PolyOne 고양이에 대응하는 경로가 40개 중 0개다. 바로 컨트롤러에 연결해 사용할 수 없으며, 뼈대 간 동작을 옮기는 리타기팅 작업이 필요하다. 현재는 원본 보관 상태다.
- 먹기·잠들기·깨기·공놀이 등의 완성 동작은 이번 임포트에 포함되지 않는다. Rip Vertices 추가 동작의 게임 연결과 리타기팅은 수행하지 않았다.

## 제외한 파일

강아지, 데모 씬·스크립트, 나머지 가구·체스 모델·아이콘, 리얼 고양이의 렌더링 구성, 중복 대기·달리기와 죽기 동작은 제외했다. 선풍기의 바람 VFX는 Visual Effect Graph 의존성을 추가해야 하므로 모델만 가져왔다. `Packages/manifest.json`과 프로젝트 설정은 가져오지 않았다. 창문은 외부 에셋 임포트 대상이 아니다.
