# M2-1 고양이 반응표 기반

기존 [고양이 종류](../Design/적/고양이_종류.md)·[공통 규칙](../Design/적/고양이_공통.md)을 `CatReactionRules`의 순수 함수로 옮겼다. 입력받은 종류·상태·목표·자극만 사용하며 씬, 현재 시간, 난수, 에셋 값을 바꾸지 않는다.

## 판정과 연결

- `EvaluateNoise`: 소리 5종, 쥐/공 출처, 유효한 미끼·내성·단계를 받아 무시·조사·미끼/공 따라가기·기상 질주·놓침 시간 갱신을 반환한다. 공 멈춤은 Loud를 유지하고 출처로 사냥꾼의 공 순위를 선택한다.
- `ShouldChase`: 근접 자극도 같은 목표 순위로 비교한다. 잠든 고양이와 먹기·기절·덮치기 같은 고정 상태는 근접으로 전환하지 않는다.
- `EvaluateTrapHit`: 퇴장·재입장 대기는 피격을 거부하고, 잠든 게으름냥의 생존 피격은 기절 대신 기상 반응을 선택한다. 피해 배율과 실제 질주는 M2-2에서 연결한다.
- `EndTarget`: 조사 완료·놓침·미끼 먹기/소실·기절 종료와 이후 종류별 종료 규칙을 판정한다. 게으름냥의 먹기/귀가 종료 시점에 5단계 이상이면 잠들지 않는다.
- 같은 우선순위는 호출 순서상 새 자극으로 교체한다. 낮은 순위는 현재 목표를 유지한다. 청각 거리와 게임 정지 여부는 실제 `CatController`에서 판정한 뒤 함수를 호출한다.

D-066: 잠든 게으름냥의 플레이어 발소리는 단발 소리 판정에서 무시하고, `CatController`가 실제 이동 시간과 소음 원으로 누적한다. 몸 접촉·누적 완료는 모찌 추적으로 전환하며, 범위 안 대시는 `WakeChase`를 반환한다. 일반 근접 감지는 여전히 잠을 깨우지 않는다. 환경의 큰 소리와 함정은 기존 기상 질주를 유지한다.

`CatController`의 숫자 우선순위를 목표 종류로 바꾸고 현재 호기심냥의 소리·근접·피격 허용·목표 종료에 연결했다. 기존 치즈 소실 후 조사 거리, 공동 조사 정체 복구, 실제 이동, 미끼 내성, CSV의 추적 종료 원인은 유지한다. 종류 에셋의 반응표는 기본 Curious이며 기존 저장 ID·수치는 바꾸지 않는다. 새 상태는 기존 enum 뒤에 추가해 기존 번호를 유지했다.

## 범위와 확인

M2-1 당시에는 1·2일째와 호기심냥만 연결했다. 이후 [M2-2 게으름냥](M2_게으름냥.md)에서 3일째와 수면/기상/귀가 이동·피격 배율·5단계 강제 기상·기상음을 연결한다. 실제 공과 소리 출처 전달은 M2-3, 사냥꾼 덮치기·공놀이는 M3 범위다. 반응 함수의 통과를 이 행동들의 구현 완료로 보지 않는다.

반응표의 기대값·수면 예외·동순위 교체·우선순위·내성·잠드는 순간의 단계·고정 상태·목표 종료를 EditMode로 검사한다. 기존 실제 씬의 치즈/공동 조사 회귀 시험에 새 동순위 소리 교체, 청각 밖 무시, 새 미끼 교체를 더했다. 결과는 [작업 기록](../Tasks/m2-reaction-foundation/결과.md)에 남긴다.
