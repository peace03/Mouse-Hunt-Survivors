# M1 밤 뼈대

1일째·2일째의 밤 선택 → 최초 인트로 → 플레이·부탁 → 결과·저장을 기존 SampleScene에 연결했다. 소음 카드는 반경 15% 감소에서 5% 감소로 완화했다. 구석 생존 문제에 대한 [고양이 생활 기획](../Notes/2026-10-22_구석플레이와_M1.md)은 제안이며 아직 행동으로 추가하지 않았다.

## 플레이 흐름과 데이터

- 시작 화면에서 밤을 선택한다. 첫날을 생존하면 둘째 날이 열린다. 3~7일째는 준비 중으로 표시하며 시작할 수 없다.
- 첫날: 45초 × 5단계, 호기심냥 1/2/2/3/3, 컵만 사용, 미끼 내성 없음. 둘째 날: 60초 × 5단계, 호기심냥 2/2/3/3/4, 컵·청소기 사용, 내성 30초.
- `Environment/Resources/Campaign/Nights`의 Night1/Night2 에셋이 구성·길이·규칙·부탁·문구를 보관한다. `CuriousCat.asset`은 종류의 기본 능력이다. 추적 배율은 GameController에서 한 번만 곱하며 공유 에셋을 판 도중 바꾸지 않는다.
- 고양이 풀의 비어 있는 슬롯에 종류를 배정해 펫도어에서 입장시킨다. 재입장할 때 종류를 유지한다. 밤 데이터의 잘못된 수치·중복 종류·감소 구성·슬롯 초과를 거부한다.
- [M1 지도](M1_맵.md)의 거실 고리를 한 바퀴 돈 청소기는 충전독에서 멈춘다. 충전독 3m 안전 규칙은 유지한다. 첫날 청소기 모델은 남지만 작동하지 않고 가까이서 회색 안내를 표시한다.
- 인트로 3장은 첫날 최초 선택 때 한 번, 아무 키·클릭으로 다음 장, Esc로 건너뛴다. 이동/미끼/컵 안내도 조건을 처음 충족할 때만 저장해서 표시한다. 새 요소 배너 중 게임은 계속 흐른다.

## 부탁과 기록

첫날 '깨진 컵'은 컵 한 번에 서로 다른 고양이 2마리, 둘째 날 '대청소'는 청소기 한 바퀴에 서로 다른 고양이 2마리를 맞히면 달성한다. 여러 작동의 1마리씩을 합치지 않는다. CSV와 별개인 RunEvents가 HUD 판정에 쓰인다. 동시 치명타는 모두 정산한 뒤 아침을 당겨 승리 직전의 두 번째 타격도 빠지지 않는다.

생존 별, 생존한 판의 부탁 별, 최다 퇴장 기준 별은 서로 다른 생존 판에서도 누적한다. 패배의 부탁·퇴장 수·시간은 원기록을 개선하지 않는다. 최단 기록은 실제 진행 시간이다. 다시 하기는 현재 밤을 초기화하고, 밤 선택은 제목 상태에서 새 밤을 고른다.

진행 파일은 `Application.persistentDataPath/campaign-v1.json`이다. 설정 PlayerPrefs·측정 CSV와 분리한다. 이름 ID와 형식 버전 1, 인트로/안내 여부, 밤별 생존·부탁·최다 퇴장·최단 시간만 저장한다. 별/해금은 읽을 때 현재 목표로 다시 계산한다. 정상 파일 교체 시 직전 정상본 `.bak` 하나를 유지한다. 손상/미지원 버전/잘못된 수치는 덮어쓰지 않고 UI에 저장 오류를 표시한다. 중단된 판의 실시간 진행은 저장하지 않는다.

## 검증 경계

치즈를 다른 고양이가 먹었거나 치즈가 사라진 뒤에는 기존 먹기 거리(0.6m) 안에서도 미끼 자리 도착으로 인정한다. 서로를 피하는 여러 고양이가 중심 0.3m까지 접근하지 못해 물음표로 고정되던 문제를 수정했다. 두리번 뒤 순찰하는 규칙과 일반 조사 거리는 유지한다. [재현과 수정 결과](../Tasks/bait-stuck/결과.md).

스위치·소리 등 공통 조사에서도 고양이들이 서로 막혀 실제 이동이 진행되지 않으면 기존 조사 대기 시간 동안 기다린 뒤 현재 자리에서 두리번거리고 순찰로 복귀한다. 정상 이동·새 목표에서는 정체 시간을 초기화하며, 한 번 두리번을 시작한 뒤 작은 밀림 때문에 도착을 다시 기다리지 않는다. [공동 조사 정지 수정](../Tasks/investigation-stuck/결과.md).

새 테스트는 데이터 검증, 원기록 누적, 파일 손상 보호, 실제 씬 부탁·밤 전환·초기화, UI 흐름, 지도 장애물 검사를 포함한다. 기계 실행 결과와 현재 빌드는 [작업 결과](../Tasks/m1-night-foundation/결과.md)에 기록한다. 이전 M0의 통과 기록으로 M1을 통과 처리하지 않는다.

사람이 확인할 항목: 1·2일째 각각 연속 5판의 생존/퇴장/완료 시간, 부탁 3판 안에 1회 달성, 첫 카드의 소음 원 변화, 서로 다른 화면 비율의 글 읽기와 인트로 입력, 거실 경로와 모델의 시각적 간섭. 구석 생존률과 재미는 이 자동 검사로 판정하지 않는다. [M2-1 반응표 기반](M2_반응표.md)을 추가했으며 이후 고양이 실제 행동·장난감 공·정식 카드 9장·리깅은 미구현이다.
