# M2-2 게으름냥과 시작 대기

기존 [고양이 종류](../Design/적/고양이_종류.md)의 게으름냥을 실제 이동·피격·미끼에 연결한다. 2일째 생존 후 3일째가 열리고 호기심냥 한 마리와 게으름냥 두 마리로 시작한다. 공과 4일째는 [M2-3 장난감 공](M2_장난감_공.md)에 연결했다.

## 플레이 규칙

- 게으름냥은 체력 5, 서로 다른 두 자리에서 수면으로 시작한다. 잠든 동안 쥐를 잡지 않지만 모찌와 몸이 닿으면 즉시 깨어 모찌를 추적한다. 접촉은 두 개체의 몸 반경 합으로 판정한다.
- D-066에 따라 실제 걷기·달리기 소음 원 안에서 연속 노출을 누적한다. 걷기 3초·달리기 1.5초가 초기값이며, 걷다 뛰면 같은 게이지를 더 빨리 줄인다. 고양이 발밑의 원형 수면 게이지는 반경을 유지하고 원호가 줄어들며, 다 없어지면 모찌를 추적한다. D-067에 따라 범위 밖·정지·살금살금·대시 후 무음에는 수면 게이지를 서서히 회복한다. 전체 회복 기준 6초로, 걷기 감소 속도의 절반·달리기의 4분의 1이다. 덜 회복된 채 다시 소음을 들으면 남은 누적량에서 이어진다. 준비·일시정지에는 진행하지 않는다.
- 잠든 고양이가 대시 시작 지점의 잔상 소음 원 안에 있으면 즉시 깨어 모찌를 추적한다. 수면 누적과 대시 기상 범위는 화면의 소음 원과 같으며 별도의 청각 배율을 더하지 않는다. 깨어 있던 고양이는 기존처럼 잔상으로 유인한다.
- 환경의 큰 소리 또는 살아남은 수면 피격은 기존처럼 처음 들린 지점(피격이면 스위치)으로 5.5m/s, 최대 6초 질주한다. 질주 중 큰 소리·미끼는 목표를 바꾸지 않으며 잔상과 근접은 반응표 순위를 따른다. 기상음은 같은 프레임에 여러 마리가 깨어도 한 번만 재생한다.
- 수면 중 함정 피해는 2배다. 살아남으면 기절·밀림 없이 질주하며, 퇴장하면 기존 아침 당김·치즈 보상을 받는다.
- 깨어 있을 때 미끼를 먹으면 1.5초 뒤 먹은 자리에서 잠든다. 먹는 동안에도 쥐를 잡고 30초 내성을 유지한다. 추적·기상 질주는 미끼보다 우선한다.
- 목표 조사 후 지정된 자리로 걸어가 잠든다. 퇴장 후 재입장도 펫도어에서 수면 자리로 걸어간다.
- 5단계에는 수면·귀가·미끼 이동을 종료하고 순찰한다. 이미 먹던 미끼를 마쳐도 다시 잠들지 않으며 이후 미끼를 무시한다.
- 3일째 ‘자장가’ 부탁: 미끼로 재운 뒤 함정으로 맞히기를 두 번 달성한다. 최초 수면·자연 귀가 수면과 깨어난 뒤 연속 타격은 세지 않는다. 생존해야 부탁 성공을 원기록에 저장한다.

## 첫 키 입력

D-065에 따라 밤 선택·인트로·재시작 뒤 `Ready` 상태에서 기다린다. ‘아무 키나 누르면 밤이 시작됩니다’를 표시하고 게임 시계·실제 생존 시간·고양이·함정·플레이어를 정지한다. 키를 모두 놓은 뒤 새로 누른 키로 시작한다. 마우스 클릭은 시작하지 않는다. 시작 키는 그 프레임의 대시·상호작용·일시정지·디버그 입력으로 중복 처리하지 않는다. 이동 키를 계속 누르면 다음 프레임부터 움직인다.

## 확인 범위

자동 시험은 세션 정지, 실제 키 입력과 재시작, 3일째 슬롯, 수면 피해, 미끼 수면과 부탁 집계, 근접 우선순위, 5단계 전환, 실제 NavMesh 귀가와 일시정지를 검사한다. [작업 결과](../Tasks/m2-lazy-cat/결과.md)에 실행 결과를 기록한다.

추가 기상 규칙은 실제 이동 입력으로 수면 게이지·걷기/달리기 시간·소음 카드 범위·접촉·대시·정지/살금살금/일시정지/재시작을 검사한다. 이번 실행 근거는 [기상 규칙 결과](../Tasks/lazy-wake-stimuli/결과.md)에 기록한다. 시간 조절 위치는 `Campaign/LazyCat`의 `Walk Wake Seconds`와 `Run Wake Seconds`다.

외형은 기존 고양이 모델과 상태 기호(`Zzz`·`!!`·`z`)를 사용한다. 전용 수면 애니메이션과 종류별 외형 구분은 모델·애니메이션 작업에 남아 있다. 자동 검증은 사용자의 직접 플레이·난이도 평가를 대신하지 않는다.

D-067 회복 시간은 `LazyCat` 에셋의 `Sleep Recovery Seconds`로 조절하며 걷기·달리기 기상 시간보다 길어야 한다. [회복 변경 결과](../Tasks/lazy-sleep-recovery/결과.md)에서 점진 회복·재노출·일시정지와 기존 행동 검증을 확인한다.
