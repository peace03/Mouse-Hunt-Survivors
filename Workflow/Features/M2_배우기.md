# M2-4 배우기 장치

패배 결과 화면에서 마지막 하트를 잃게 한 고양이와 당시 행동, 다음 판에서 쓸 대처 요령을 보여 준다. 소리 조사와 미끼 이동·먹기를 구별한다. 기록은 유효한 마지막 피격에만 만들며 무적·판 종료 후 피격으로 바꾸지 않는다. 새 판은 지우고 생존 결과에는 표시하지 않는다. 측정 CSV도 실제 종류를 기록한다.

제목 화면과 Esc 일시정지 메뉴의 ‘조작과 생존 요령’에서 조작·공 재차기와 만난 고양이 요약을 읽는다. Esc는 도움말만 닫고 일시정지 메뉴로 돌아간다. 고양이 정보는 첫 키로 판을 시작할 때의 초기 종류와 이후 실제 입장한 종류만 저장한다. 밤 선택·해금만으로는 공개하지 않는다. 저장은 기존 `campaign-v1.json`의 선택 필드 `encounteredCats`에 추가한다. 예전 생존·별·안내 기록을 유지하며 종류 기록은 이후 만남부터 쌓는다. 손상 파일은 기존 보존 정책을 따른다.

게으름냥 요약은 발소리 원 안 누적, 원 밖의 느린 회복, 접촉·원 안 대시의 즉시 기상, 큰 소리의 기상 질주, 미끼 수면·수면 중 두 배 피해를 설명한다. 이미 구현한 자장가와 ‘깨워서 한 방’ 부탁 판정은 유지한다. 새 요소 배너도 기존 구현을 유지하며, 준비 상태에서 오래 기다려도 실제 시작 뒤 표시 시간을 다시 잡는지 검사한다.

`CatLearning`에 문구와 피격 분류, `CampaignProgress`에 만남 기록, `GameController`에 실제 피격·입장 연결, `GameHud`에 화면을 둔다. 기존 Canvas와 키보드 초점 복귀를 재사용한다. 사냥꾼 요약은 기획 문구만 있으며 실제 만남 기록이 생기기 전까지 표시하지 않는다. 사냥꾼 행동 구현은 M3이다.

검증은 저장 왕복·예전 파일·손상 보존, 피격 목표 구분, 실제 게으름냥 접촉 후 결과, 재시작·승리, 도움말의 공개 범위·키보드 복귀·텍스트 영역, 시작 배너를 포함한다. 결과와 미검증 항목은 [작업 결과](../Tasks/m2-learning/결과.md)에 기록한다. M2-5 외형 구분 시험·모델링 시작 판단과 사람 플레이는 별도로 남아 있다.
